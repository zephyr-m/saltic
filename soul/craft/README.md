# Craft

Инструменты разработчика, протоколы и студия Saltic, работающие поверх языка.

Трассировка исходника запускается командой `just trace путь.saltic`, готового
образа — `just trace-elf путь.elf`. Трассер печатает вызовы и возвраты сразу,
не накапливая журнал в памяти.

Минификация запускается командой `just minify путь.saltic`. Результат записывается
рядом как `путь.min.saltic` и сразу проверяется парсером. Отдельный модуль не
компилируется как программа без своего владельца и точки входа.
