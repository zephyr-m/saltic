# Core

Переносимая стандартная библиотека Saltic, написанная на Saltic поверх `seed`.

Здесь находятся базовые типы данных, ввод-вывод, файлы, время, память,
синхронизация, процессы и переносимые системные возможности. Код этого слоя не
должен зависеть от конкретного оборудования и реализаций протоколов.
