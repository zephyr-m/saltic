# Движки — заготовка

Папка для больших подсистем на Saltic, которые живут поверх языка и ядра и
нужны многим программам сразу. Кода пока нет.

Первый кандидат — **движок игр и симуляций**: у каждой сущности есть «ДНК»
(формулы и правила роста), из которой вырастает и игровая модель из зёрен, и
тело для симуляции из простых фигур с массой, инерцией и контактом. Замысел —
[docs/os/Engine-idea.md](../../docs/os/Engine-idea.md), это замысел, а не
решение.

Почему он нужен: эволюция паука (`os/target/uefi_x86_64/programs/pauk`, ветка
`beam/pauk`) упёрлась в самодельную физику на целых числах — без костей,
суставов и честного контакта обучение выходит случайным. Физический движок и
редактор модели паука — ровно то, что сюда ляжет.

Устройство, границы и порядок работ решает автор.
