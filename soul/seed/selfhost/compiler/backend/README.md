# Бэкенды компилятора

Каждый бэкенд — машинный код одного семейства процессоров. Папка с одним
`README.md` — заглушка: бэкенд записан в план, но ещё не начат. Подробно —
`docs/plan/PLAN-3.md`, раздел «Железо и бэкенды»; порядок работ — там же.

Общее лицо — `../backend.saltic`, **договор машины**: роли регистров
(`VALUE`, `ERROR`, `ARG2…`, `SCRATCH0…`, `FRAME`, `STACK`, `HEAP_TOP`, …;
`ROLE_COUNT` = 21) и операции («положи число», «загрузи слот», «вызови», «перейди, если ноль»,
«вызов платформы»…). `codegen`, `functions`, `state` и рантайм `rt_*`
(`rv32i/runtime/`) говорят только на нём — методами Box-исполнителя в
`compiler.executor`. Новый бэкенд = Box с теми же методами (образец —
`rv32i.Executor`) плюс образ и платформа; рантайм достаётся бесплатно.
