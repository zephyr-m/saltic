# Xtensa — заглушка

⬜ **Не начат.** Записан 03.11.2026.

- **Набор команд:** Xtensa LX6 (ESP32) и LX7 (ESP32-S3).
- **Что откроет:** ESP32-CAM, ESP32-WROVER, ESP32-S3 (DevKitC N16R8, XIAO
  Sense, Arduino Nano ESP32) — самое массовое железо: Wi-Fi, камера,
  векторные команды для ИИ.
- **Главная сложность:** окна регистров. Wi-Fi закрыт прошивкой Espressif.
- **Когда:** эпоха 3, порядок работ — п. 3.
- **Документация:** Xtensa ISA Reference Manual (Cadence), ESP32 и ESP32-S3
  Technical Reference Manual (Espressif).
- **Подробно:** `docs/PLAN.md, раздел «Железо и бэкенды»`.
