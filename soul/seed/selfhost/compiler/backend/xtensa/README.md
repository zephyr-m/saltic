# Xtensa

Кодировщик CALL0, исполнитель договора (`xtensa.saltic`) и прошивка «S».
Образ — `formats/esp`. Платформа — `os/target/esp32`. Записан 03.11.2026.

- **Состояние (13.11.2026):** на DevKit (D0WD-V3) работают группы, рекурсия,
  Box, деление и склейка текста; UART 115200. Кодировщик сверен с GNU as
  Espressif (настройка ядра ESP32): `tests/xtensa-encoder`, 57 команд.
- **Роли:** a2–a15 в регистрах, ARG4…ARG7 и низ побега — слоты в DRAM;
  a14/a15 — ещё и временные, прежние значения ждут на стеке (`access`).
- **Память:** арена и куча по умолчанию — у платформы (`os/target/esp32`).
- **hello / check:** первая ручная прошивка «S» мимо исполнителя и проверка
  её образа.

- **Набор команд:** Xtensa LX6 (ESP32) и LX7 (ESP32-S3).
- **Что откроет:** ESP32-CAM, ESP32-WROVER, ESP32-S3 (DevKitC N16R8, XIAO
  Sense, Arduino Nano ESP32) — самое массовое железо: Wi-Fi, камера,
  векторные команды для ИИ.
- **Главная сложность:** окна регистров. Wi-Fi закрыт прошивкой Espressif.
- **Когда:** эпоха 3, порядок работ — п. 3.
- **Документация:** Xtensa ISA Reference Manual (Cadence), ESP32 и ESP32-S3
  Technical Reference Manual (Espressif).
- **Подробно:** `docs/plan/PLAN-3.md`, раздел «Железо и бэкенды».
