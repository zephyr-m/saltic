# x86-64 родной — заглушка

⬜ **Не начат.** Записан 03.11.2026.

- **Чем отличается от `x86_64_translation/`:** сейчас x86-64 получается
  переводом готового кода RV32I: 32 регистра RISC-V втискиваются в 16
  регистров x86, лишние пересылки, ни одной сильной команды x86. Отсюда
  fib в 20 раз медленнее C. Родной бэкенд строит код x86-64 прямо из
  программы, без RV32I посередине.
- **Что откроет:** скорость на Acer, ПК, Steam Deck; тот же Linux и UEFI.
- **Когда:** эпоха 2 — оптимизация (`docs/PLAN.md`, «Скорость»).
- **Документация:** Intel 64 and IA-32 Software Developer's Manual, AMD64
  Architecture Programmer's Manual.
- **Подробно:** `docs/PLAN.md`, разделы «x86-64» и «Железо и бэкенды».
