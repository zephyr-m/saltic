# ARM64 — заглушка

⬜ **Не начат.** Записан 03.11.2026.

- **Набор команд:** AArch64 (ARMv8-A и новее) — не Thumb-2, отдельный бэкенд.
- **Что откроет, ступеньками:** программы под Linux и Android (статический
  ELF, Termux) → Raspberry Pi 4/5 и Orange Pi на голом железе («головной
  мозг» робота) → своя ОС на телефоне — мечта на потом.
- **Когда:** эпоха 3, порядок работ — п. 4.
- **Документация:** Arm Architecture Reference Manual for A-profile (ARM).
- **Подробно:** `docs/PLAN.md, раздел «Железо и бэкенды»`.
