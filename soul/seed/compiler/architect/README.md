# Архитектор

Первая ступень сборки, до лексера и парсера:
`architect` → `parser` → `checker` → `compiler`. Код — `main.saltic`
(Box `Architect`, `use compiler.architect`): с 21.11.2026 он собирает программу
по `use` — бывший загрузчик парсера.

## Законы в силе

Пока законы — **советы**, не ошибки (решение автора 21.11.2026): сборка идёт,
советы лежат в `Load.advice`, `told(load)` печатает их построчно —
«архитектор советует: …». Когда совет станет ошибкой, решает автор.

1. **Один способ записать модуль** (21.11.2026): модуль — либо файл `a/b.saltic`,
   либо папка `a/b/` со входом `main.saltic`. Файл и папка того же имени рядом —
   совет `module_doubled`: перенеси файл в папку как `main.saltic`.
2. **Одно имя — один угол** (21.11.2026): `use` ищет модуль по углам —
   `soul/seed/`, потом `soul/`, потом корень проекта; таблицы путей нет. Имя,
   которое есть в двух углах сразу, — совет `module_shadowed`: `use` всегда
   возьмёт раннее, позднее остаётся в тени — переименуй одно.
