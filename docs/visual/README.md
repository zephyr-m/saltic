# Visual references

Эта папка хранит первые визуальные ориентиры S.

Важно: текущие HTML-файлы не являются renderer языка S.

Это визуальные прототипы, которые помогают понять, каким должен быть будущий `render/observe` слой.

## 001 engineering crystal

Файл:

```text
engineering-crystal.html
```

Канон:

```text
rotating square bipyramid
```

Смысл:

- две квадратные пирамиды с общим основанием;
- форма читается как простой физический primitive;
- вращение показывает состояние во времени;
- инженерная бумага подчёркивает, что это не декоративный арт, а наблюдение формы;
- cyan-рёбра и грани связывают primitive с кристаллом и техничностью.

Почему это важно:

```text
S не должен оставаться только текстом.
Если язык ориентирован на физический мир, у него должен быть визуальный способ наблюдать состояние.
```

## Не канон renderer

Пока не зафиксировано:

- `core.render`;
- canvas API;
- 3D API;
- material model;
- animation model;
- scene graph;
- camera model.

Следующий шаг должен быть не "сделать движок", а маленькая проверка:

```text
S scene -> visual observation
```

То есть S-программа описывает простую форму, а toolchain показывает её как наблюдаемую картинку.
