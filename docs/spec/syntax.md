# Синтаксис

Этот документ фиксирует текущий синтаксис `v0.1`.

Основное правило: одна базовая задача должна иметь одну очевидную форму записи.

## Точка входа

```s
program() {
    out none
}
```

`program(...)` — обязательная точка входа для исполняемого файла.

## Переменные

Переменные объявляются через `@`.

```s
@x
x = 10
```

Первое присваивание фиксирует тип.

```s
@x = 10
x = 20
```

## Константы

Константы используют имя с большой буквы и не требуют отдельного ключевого слова.

```s
MaxRetries = 3
AppName = "S Language"
```

## Modules

Для v0.1 принят минимальный импорт стандартной библиотеки:

```s
use std
```

`use std` разрешает явные пути `std.io.*`, `std.file.*`, `std.str.*`, `std.num.*`, `std.group.*` и `std.json.*`.

Короткие имена не импортируются.

## Функции

Функции объявляются через `skill`.

```s
skill add(a, b) {
    out a + b
}
```

`out` возвращает значение.

## Условия

S использует условный блок в форме, которую parser распознаёт как `if`.

```s
(x > 0) {
    host.io.println("positive")
}
```

## Выбор

Выбор по enum-подобному значению parser распознаёт как `switch`.

```s
(status) {
    .OK => host.io.println("ok"),
    .ERROR => host.io.println("error"),
    .PENDING => host.io.println("pending"),
}
```

## Циклы

Все циклы v0.1 используют `drum`.

```s
drum (5) {
    host.io.println("tick")
}
```

`drum` пока поддерживает только числовой счётчик.
