# Типы

S использует вывод типов по умолчанию, но должен оставлять возможность явной записи там, где это нужно для системного кода.

## Вывод типа

Первое присваивание фиксирует тип.

```s
@x = 10
x = 20
```

Позднее присваивание несовместимого типа должно быть ошибкой проверки.

## None

`none` — маркер пустого значения.

```s
@value = none
```

Связь между `none`, optional-значениями и `Box` ещё требует точного определения.

## Box

`Box` — основная идея структурированного контейнера данных.

Текущий канон формы описан отдельно: [Box v0](box-v0.md).

В текущей реализации `Box v0` поддерживает объявление формы, создание значения с defaults и доступ к полям через точку.

```s
Player = Box {
    name = ""
    hp = 100
    inventory = none
}

@player = Player {
    name = "Zephyr"
    hp = 999
}
```

`Box` должен уменьшать количество решений для человека и агента. Он не должен превращаться в сложную объектную систему.

Открытые вопросы:

- заменяет ли `Box` все структуры;
- какие у `Box` семантики: value, reference или обе;
- как `none` работает внутри полей;
- как задаются layout, alignment и ABI для низкоуровневого кода.

## Group

`Group` — конечная группа значений.

Текущий канон формы описан отдельно: [Group v0](group-v0.md).

```s
@objects = [
    Object { name = "PLAYER" },
    Object { name = "LIGHT" },
    Object { name = "WALL" },
]
```

`Group v0` сохраняет порядок записи для детерминированного обхода через `drum`.

```s
@index = 0
drum (std.group.count(objects)) {
    @object = std.group.at(objects, index)
    index = index + 1
}
```

`Group` не является системным `Array`. Layout памяти, capacity, slices и pointer semantics остаются отдельным будущим решением.

## Enum

```s
Status = enum {
    OK,
    ERROR,
    PENDING,
}
```

## Union

Union по умолчанию tagged.

```s
Response = union {
    ok: Box,
    err: []const u8,
}
```

В примерах пока есть Zig-подобные фрагменты. Нужна собственная нотация S для строк, массивов, указателей и slices.

## Массивы

```s
@arr = i32[1, 2, 3, 4, 5]
```

Системные массивы, slices, строки и указатели ещё не финализированы. `Group v0` закрывает только высокоуровневую запись группы значений.
