Одна вещь — один способ. У других — сколько угодно.

Слева Saltic: у каждой вещи ровно одна запись. Справа тот же кусок на выбранном языке и все способы, которыми его пишут в живом коде, — только сам язык и его стандартная библиотека, без сторонних. Каждый пример на Saltic собран компилятором 142:37 и запущен.

1 · привет

Вставка в строку

Имя в фигурных скобках прямо внутри строки, без приставки f и без %s. Склейка, форматы и шаблоны не нужны: строка пишется так, как её прочтут.

2 · переменные

Новая или та же

@ — новая переменная, без @ — изменить уже существующую. Других записей нет, поэтому опечатка в третьей строке не может тихо создать новую переменную. Под каждым способом других языков — что будет с той же опечаткой.

3 · навыки

Функция

Функция в Saltic — skill, навык. Результат — out. Типы не пишутся: чекер выводит их сам. Ни стрелок, ни лямбд, ни методов-однодневок.

4 · условия

Если и иначе

Слова if нет: условие в скобках и есть «если». Цепочка — pick: выполняется первая подходящая ветка, ветка без условия — «иначе». Ни тернарного оператора, ни switch (true), ни and/or-трюков.

5 · цикл

Барабан

drum — барабан: стучит заданное число раз, beat — номер удара, с нуля. Выйти раньше — leave. Счётчик руками не заводится, while, рекурсии ради цикла и forEach нет. Имя от saltare: «прыгать» и «танцевать».

6 · Box

Структура со значениями по умолчанию

Значения по умолчанию пишутся прямо в объявлении. Point {} — всё по умолчанию, Point { x = 5 } — меняем только то, что назвали. Ни классов с конструкторами, ни словарей вместо структур.

7 · enum

Перечисление и выбор

Значение в скобках, под ним варианты через =>. Внутри выбора имя типа повторять не нужно: .READY вместо State.READY. Перечисление — только enum: не строки, не числа-константы, не объект-заглушка.

8 · ошибки

Ошибка — значение с именем

out error.NotEnoughEnergy — навык отдаёт ошибку вместо результата. Она сама поднимается выше, пока её не поймает rescue, и rescue отдаёт значение на замену. Объявлять класс ошибки не нужно, достаточно имени. Ни None вместо ошибки, ни паники, ни способа молча её выбросить.

9 · группы

Список и выход за край

Группа — […], работа с ней — модуль core.group. Взять элемент за краем — ошибка GroupBounds: её можно поймать, но нельзя не заметить. Отрицательных индексов и тихого undefined нет.
