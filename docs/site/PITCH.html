Один способ

Девять базовых вещей — строка, переменная, функция, условие, цикл, структура, перечисление, ошибка, список. В Saltic на них 9 записей, в Python мы насчитали 70, в JavaScript — 68. Каждый лишний способ — шанс, что агент выберет не тот, а следующий агент его не поймёт. Потыкай сам.

как выглядит

Читается с первого раза.

use io

skill spend(energy, cost) {
    (cost > energy) { out error.NotEnoughEnergy }
    out energy - cost
}

skill buy(energy) {
    @left = spend(energy, 40)
    out left
}

program() {
    @left = buy(30) rescue |err| {
        io.show("не вышло: {err}")
        0
    }
    drum (3) {
        io.show("шаг {beat}")
    }
    out none
}
skill … out

Функция — навык, результат — out. Типы чекер выводит сам.

out error.NotEnoughEnergy

Ошибка — значение с именем. Объявлять класс не нужно.

@left = spend(…)

Ошибка из spend поднимается сама — без ? и if err != nil.

rescue |err| { … }

Ловит там, где написано, и отдаёт значение на замену.

drum / beat

Цикл — барабан, шаг — удар. Счётчик руками не нужен.

честно

Чего ещё нет.

Мы обещаем, что ничего не молчит. Значит, и про себя молчать не будем.

Пока не быстрее C

x86-64 теперь родной, без RISC-V посередине: рекурсивный fib втрое быстрее, чем был через перевод, и обгоняет PHP, Lua, Ruby и Python. Но это всё ещё в 1,7 раза медленнее C без оптимизаций и в 8 раз — C с -O2. Оптимизации — следующая эпоха.

Числа 29-битные

Дробных чисел пока нет, 64-битных целых тоже. Решено, что будут, — форму выбирает автор.

Синтаксис ещё не заморожен

Перед заморозкой — always, проверка на пустое значение, <=. После неё код на Saltic будет жить годами без переписываний.
