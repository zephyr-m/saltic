Проверки

Saltic не прячется за своими тестами. Здесь — внешние проверки, которые проект собирается пройти: значки качества открытых проектов, воспроизводимость сборки, официальные наборы тестов на соответствие стандартам и бенчи. Всё бесплатное; платное — отдельно внизу, честно.

Почему это важно. Обычно такие значки есть у проектов с командами и фондами — Kubernetes, curl, OpenSSL. Когда их проходит проект одного человека, это говорит о дисциплине, а не о размере.Сначала — OpenSSF Best Practices (passing) и Scorecard: оба быстрые. Для них репозиторий должен быть публичным, с лицензией Apache 2.0 (с 11.11.2026).

Значки открытого проекта

Проверяют не код, а то, как устроен проект: лицензия, тесты, безопасность, релизы.

Что стоит денег

Тестовые наборы у них обычно открыты — прогнать можно бесплатно. Платят за официальную бумагу: лаборатории, членство, взносы.

  • FIPS 140-3 — сертификат криптомодуля для госзаказов США, через аккредитованную лабораторию (CMVP).
  • Common Criteria — международная сертификация безопасности продукта (commoncriteriaportal.org).
  • Знак соответствия Khronos — для своей реализации Vulkan или OpenGL нужно членство (khronos.org/conformance).
