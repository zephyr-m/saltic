Поток

Та же программа, нарисованная схемой. Блоки — навыки и их части, линии — данные, коралловым — путь ошибки через rescue, фиолетовым пунктиром — типы. Таскай блоки, двигай холст, колесом приближай. Двойной клик по блоку покажет его строки в тексте.

SalticIDE workbench/actor.saltic
тащи блок · тащи фон · колесо — масштаб · двойной клик — в текст
данные ошибка тип следующий удар drum 

  


  

    
Одна программа — два вида
Схема собрана из того же текста: у каждого блока свои строки. Переключатель сверху меняет только вид.

    
Путь ошибки виден
NotEnoughEnergy уходит коралловой линией в rescue и возвращается актёром TIRED. Где программа может свернуть, видно до запуска.

    
Цвета те же
Навыки зелёные, типы фиолетовые, данные бирюзовые, ошибки коралловые — как в SalticIDE и в VS Code.
