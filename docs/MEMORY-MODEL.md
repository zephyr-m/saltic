# Модель памяти Saltic

**Статус:** действующая модель, реализована в коммите `9e38e84`.

Заменяет `MEMORY-MODEL-V1-FAST-PATH.md` и `MEMORY-MODEL-PROPOSAL.md`, которые
перенесены в `.archive/docs`.

## Основное правило

Программа получает одну квоту памяти. Каждый вызов skill открывает регион.
Всё, что skill создал, принадлежит его региону. Когда skill завершается,
результат `out` переходит вызывающему, а остальная память региона
освобождается целиком.

Модуль-файл отдельного региона не получает: вызов skill из другого файла уже
является границей региона.

Сборщика мусора нет. Runtime не ищет недостижимые объекты, а переносит только
то, что выходит из региона. Работа пропорциональна размеру результата, а не
количеству мусора.

## Куча

```text
saltic_heap                                             конец квоты
│ объекты родителей │ регион текущего skill │ свободно │ список побегов │
                    ↑S4                     ↑S1        ↑S2             ↑S5
```

- `S1` — следующий свободный байт.
- `S2` — граница выделения. Ниже конца квоты растёт список побегов.
- `S4` — начало региона текущего skill.
- `S5` — начало сегмента побегов текущего skill.

Кадр skill сохраняет `S4` и `S5` вызывающего и восстанавливает их на выходе.
Выделение памяти по-прежнему одно: последовательное движение `S1`.

## Выход из skill

1. Если skill ничего не выделил, ничего не происходит.
2. Иначе корнями становятся значение `out` и поля, записанные в список побегов.
3. Новые объекты, достижимые из корней, копируются за верхнюю границу региона.
   Общие подобъекты не дублируются.
4. Копия сдвигается в начало региона, указатели поправляются.
5. `S1` встаёт сразу за копией. Всё остальное освобождено.

Если `out` имеет фиксированный тип (`u8`, `u32`, `address`…), значение не
считается указателем.

Если для копии не хватает свободного места, перенос откатывается: регион не
освобождается и становится частью региона вызывающего. Данные остаются
целыми.

## Список побегов

Box изменяется на месте. Запись в поле Box значения, которое моложе самого Box,
регистрируется в списке побегов. Так значение переживает регионы между Box и
местом записи. Запись поднимается от сегмента к сегменту вызывающих, пока не
дойдёт до региона, которому принадлежит Box.

Ячейка константы регистрируется так же: значение константы живёт всё время
работы программы.

## Нехватка памяти

Если объект не помещается, текущий skill завершается с системной ошибкой
`MemoryExhausted` (номер 8). Его регион освобождается. Вызывающий может
поймать ошибку через `rescue` и продолжить работу.

Код завершения 65 остаётся только для нехватки памяти до запуска `program`,
когда ещё нет ни одного skill.

## Ограничения

- Мусор, созданный в цикле внутри одного skill, освобождается только на
  выходе из этого skill. Долгую работу нужно разбивать на вызовы.
- Значения фиксированных типов в полях Box runtime не отличает от
  указателей. В группу и в параметр навыка чекер их не пускает.
- Адреса, записанные через `seed.mem.store_address32` в сырую память, не
  отслеживаются.
- Нехватка памяти прямо внутри вычисления константы оставляет константу в
  состоянии «вычисляется».
- Проверки времён жизни в компиляторе нет.
