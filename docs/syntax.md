# Синтаксис

Этот документ фиксирует текущий черновик синтаксиса `v0.1`.

Основное правило: одна базовая задача должна иметь одну очевидную форму записи.

## Переменные

Переменные объявляются через `@`.

```s
@x
x = 10
```

Первое присваивание фиксирует тип.

```s
@x = 10
x = 20
```

## Константы

Константы используют имя с большой буквы и не требуют отдельного ключевого слова.

```s
MaxRetries = 3
AppName = "S Language"
```

## Функции

Функции объявляются через `skill`.

```s
skill add(a, b) {
    out a + b
}
```

`out` возвращает значение.

## Условия

S использует блок условия без ключевого слова `if`.

```s
(x > 0) {
    std.io.println("positive")
}
```

## Выбор

Выбор по enum-подобному значению использует ту же форму со скобками.

```s
(status) {
    .OK => std.io.println("ok"),
    .ERROR => std.io.println("error"),
    .PENDING => std.io.println("pending"),
}
```

## Циклы

Все циклы используют `drum`.

```s
drum {
    stop
}

drum (5) {
    std.io.println("tick")
}

drum (item in items) {
    std.io.println(item)
}
```

`stop` выходит из цикла.

## Импорт

Модули подключаются через `use`.

```s
use std.io
use core.math
```

## Заметки

`@note` сейчас используется в черновиках как конструкция для заметок и документации.

```s
@note { This is a draft note }
```

Финальный синтаксис комментариев и документации ещё не утверждён.
