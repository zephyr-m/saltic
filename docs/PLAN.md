## Ядро ОС

Ранние заметки по ОС считаются неактуальными: `OS.md` и план миграции дерева `os/`
перенесены в `.archive/docs/`, части `docs/PHILOSOPHY.md` про ядро тоже не
являются решением. Понимание ОС автор
собирает заново, агенты помогают: исследуют, задают вопросы, показывают варианты.
Решения и состав ядра — только за автором. Код в `os/` до нового понимания не
перестраивается. Собранное понимание — `docs/OS-core.md`, открытые вопросы — там же.

## Баги

- Числа больше 2^25 по модулю компилируются неправильно: компилятор считает
  `n * 8` в своих 29-битных числах (пример: `-268435455` печатается как `1`).
  Ещё одно место — `relative_high` с `+2048`. Лечение: собирать слово
  побайтово и грузить через `emit_load_word`.
- Фиксированное значение (`i32(…)`), положенное в группу, печатается
  неправильно: в группе теряется тип. Разобраться, баг это или ограничение.

## Вектор качества

Цель — язык уровня тех, что делают серьёзные команды. Подход уже на этом уровне
(самосборка с побайтовой сходимостью, свой бэкенд, проверка правок байтами,
тесты, релизы, канон). Разрыв — в удобстве на каждый день и в инструментах.
Порядок внутри раздела — по ощутимости для автора.

### Надёжность: никаких тихих ошибок

- Числа больше 2^25 считаются неправильно (см. «Баги»).
- Молчаливое переполнение обычных чисел. **Решает автор:** ошибка,
  `rescue` или что-то своё.

### Язык

- Обращение к полю результата вызова: `f().x`. **Решает автор.**
- Склейка строк без вложенных `seed.str.add`. **Решает автор.**
- Словари. **Решает автор.**
- Равенство групп по ссылке, а не по содержимому. **Решает автор.**
- Поля со значением `none` требуют вспомогательных навыков. **Решает автор.**
- Дробные числа. **Решает автор.**
- `seed.io.show` принимает не больше 8 аргументов.
- Фиксированное значение теряет тип в группе (см. «Баги»).

### Инструменты

- Языковой сервер: подсказки, переход к определению, ошибки прямо в редакторе.
- Форматтер.
- Отладчик.

### Скорость

- Родной код в 5 раз медленнее неоптимизированного C (см. «x86-64», п. 1).

### Документация

- Справочник языка.
- Учебник для человека со стороны.
