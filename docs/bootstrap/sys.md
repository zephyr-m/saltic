# sys

`sys.*` — будущий низкоуровневый системный слой S.

Он находится ниже `std.*`, но выше прямого `c.*` или backend-specific runtime.

## Назначение

`sys.*` должен быть маленьким и явным.

Он описывает системные возможности, которые нужны стандартной библиотеке:

```text
sys.fs
sys.mem
sys.proc
sys.env
sys.clock
sys.net
sys.thread
sys.signal
sys.call
```

## Отношение к std

Обычный код должен использовать `std.*`.

`sys.*` нужен для реализации `std.*`, runtime и низкоуровневых программ.

Пример:

```text
std.file.read_text(path)
  -> sys.fs.read(path)
  -> c.fopen/c.fread/c.fclose   в раннем backend
  -> native syscall/runtime     в будущем backend
```

## Отношение к c.*

`c.*` — внешний ABI.

`sys.*` — системная модель S.

На раннем этапе `sys.*` может быть реализован через C. Позже та же функция может быть реализована через native backend или собственную ISA.

## Правило

`sys.*` не должен быть удобной обёрткой для пользователя.

Если API хочется использовать в обычной программе, ему место в `std.*`.
