# v0.1 Core

Этот документ фиксирует минимальный состав S, который должен стать каноном для ранней версии.

## Цель

S v0.1 должен позволять писать простые полезные программы без интернета и без чтения Racket кода.

## Что уже входит в core

```text
skill
program
out
const
enum
assignment
if
drum
rescue
calls
blocks
expressions
```

## Значения

```text
number
string
yes/no
none
enum
error
```

## Поведение

- `program(...)` — точка входа.
- `skill(...)` — вызываемая единица поведения.
- `out` завершает `skill` и возвращает значение.
- `drum` остаётся единственным базовым циклом v0.1.
- `rescue` обрабатывает ошибочный результат.
- переменные должны иметь предсказуемую область видимости.
- diagnostics должны показывать, где и что сломано.

## Что не входит в core v0.1

- `each`
- list/array как полноценная модель
- package manager
- self-hosting
- backend под собственную ISA
- сложная type system
- полноценный `core`
- доменные ядра вроде finance, biology или physics

Минимальный канон `core` вынесен отдельно в [core v0.1](../spec/core-v0.1.md), чтобы не смешивать ядро языка и пользовательскую библиотеку.

## Практический критерий

Если конструкция не помогает писать один из ближайших полезных примеров, она не входит в v0.1 core.

Если конструкция уже есть в ядре, она должна быть объяснима одной-двумя фразами без ссылки на философию.

## Checkpoint

v0.1 core считается адекватным только если выполняются все условия:

- можно написать и запустить маленькую программу;
- можно объяснить её через `just explain`;
- можно получить понятную ошибку;
- можно показать повторяемое поведение;
- не требуется новая языковая идея ради каждого нового примера.
