# Layers

Каноническая карта слоёв теперь живёт в
[architecture/layers](../architecture/layers.md).

Коротко:

```text
L4 packages      прикладные пакеты и эксперименты
L3 core          формальные домены мира
L2 std           базовые инструменты обычных программ
L1 runtime       выполнение, память, время, безопасность, объекты
bootstrap host   временная опора текущего backend
toolchain        инструменты разработки
target machine   будущая VM, железо и ОС
```

Главное правило: S растёт через библиотеки, домены и пакеты, а не через
раздувание ядра.
