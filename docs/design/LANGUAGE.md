# Язык вида Saltic

Один язык на весь стек: Acer, Linux, телефон, сайт. Выписан 17.11.2026 из
`docs/site/private/CONSOLE-LOOK.html` (кожа «Мягкая») и
`docs/site/private/CHECK-LOOK.html` — у них токены совпадают до цифры. Здесь —
закон для всего нового: новую страницу или программу не выверяют глазом,
а собирают из того, что ниже.

**Суть одной фразой:** тёмный графит ступенями, цвет — только по смыслу,
светится только живое, одно главное на экране, всё машинное — моноширинно.

## 1. Токены

### Ступени тьмы

Фон самый тёмный, панель на ступеньку светлее (выступает), клетка внутри
панели снова темнее (вдавлена). **Высота — светом** (решение автора
18.11.2026): чем выше поверхность, тем она светлее — боковое меню ниже
панели, выдвижная и всплывающее выше, уведомление выше всего; тень — только
для отрыва.

| роль | цвет | тон UIEngine | где |
|---|---|---|---|
| фон | `#07090d` | `ground` | под всем |
| боковое меню | `#0c1018` | — | навигация слева |
| панель | `#111723` | `panel` | карточки, ветки, панели сторон |
| панель под рукой | `#151c29` | — | наведение на карточку |
| выдвижная, всплывающее | `#182030` | — | панель справа, меню, подсказка |
| уведомление | `#1c2535` | — | всплывает поверх всего |

### Цвет по смыслу

Цвет не украшает — он говорит. Других цветов нет. Все пять — **одной
светлоты** (OKLCH L 0.80, решение автора 18.11.2026): ни один не кричит
громче другого, громкость даёт размер и свечение, а не цвет.

| смысл | цвет | тон |
|---|---|---|
| идёт, работа, прогресс, фокус | `#4ccdff` | `accent` |
| есть, живо, прошло | `#47de7c` | `up` |
| выбор, ОС, «начато», главное действие | `#e4b740` | `mustard` |
| беда, провал | `#ff9ba0` | `down` |
| агент | `#cca9ff` | `info` |

Подложка состояния — тот же цвет с прозрачностью: фон 7–8 %, рамка 35–45 %
(клетка «идёт»: фон `rgba(76,205,255,.07)`, рамка `rgba(76,205,255,.35)`);
в UIEngine — тоны с хвостом `_soft` и `_rim` у любого цвета смысла.
Тёмный текст на заливке смысла — `#120d02` на горчичном, `#06121a` на голубом.

### Отступы

Шаг 2: 2, 4, 6, 8, 10, 12, 14, 16, 22, 26. Внутри клетки 7×9, в панели
14–16, между панелями 14, между разделами 26.

### Тени и свечение

- Тень — только у поднятого: наведённая панель `0 20px 44px rgba(0,0,0,.45)`,
  выдвижная `0 30px 80px rgba(0,0,0,.6)`.
- Свечение — только у живого: главное число `text-shadow 0 0 40px` цветом
  смысла с 35 %, крутилка «идёт» `drop-shadow 0 0 3px`, точка часов.

### Движение

Пружина `cubic-bezier(.34, 1.56, .64, 1)`: появление клеток (масштаб 0.9 →
1), наведение (подъём на 1–3 px), выдвижная панель. В «Тихо» ничего не движется
само.

## 2. Правила

1. **Одно главное на экране.** Крупно, в центре, mono: число проверок,
   время, цена. Всё остальное мельче и тише.
2. **Цвет — только по смыслу** (таблица выше). Текст никогда не красится
   цветом ради красоты: слова — `ink` или `quiet`, цветной — только значок,
   полоса, рамка или само значение состояния.
3. **Светится только то, что идёт сейчас.** Закончилось — свечение гаснет,
   остаётся цвет итога.
4. **Машинное — моноширинно,** человеческое — обычным шрифтом.
5. **Подписи над и под числами — прописными с разрядкой,** тихим цветом.
6. **Ступени, рамка и свет:** глубину дают фон, панель, клетка. У панели
   рамка на ступень светлее остальных (`--panel-rim`), сверху — свет: верхний
   край светлее, тончайший блик внутри, лёгкий градиент (`--panel-light`,
   `--panel-sheen`). Прочие рамки (таблица, поля) — тихие, `line`.
7. **Под всем — сетка точек,** затухающая к краям (`--backdrop-grid`). Глаз
   её почти не видит — мозг видит (решение автора 17.11.2026).
8. **Выбор — горчичный.** Главная кнопка — горчичная заливка с тёмным
   текстом; нажатая обычная — рамка и текст голубые.
9. **Наведение:** рамка `#33405a`, подъём 1–3 px. Нажатие — без подъёма.
10. **Метка вида** — рамка цветом смысла на 35 %, текст mono 11 px тем же цветом.
11. **Образец подписан словом «образец»** — бутафории нет (закон автора).

## 4. Почему новое пока не наследует само

Цвета мягкой кожи уже лежат в тёмной теме UIEngine (`themes/soft.saltic`, выбор — `themes.named`), и
программа на жителях получает их бесплатно. Не наследуется остальное:

- **Кегли, разрядка, радиусы и отступы зашиты в каждом жителе числами,** а не
  ролями — у одного 13, у другого 14, «на глаз».
- **Половины компонентов нет жителями** (заголовок раздела с линией, клетка
  со состоянием, счётчик, главное число, кнопка с рамкой, крутилка), поэтому
  каждая программа собирает их заново и по-своему.
- **Свечения в UIEngine нет вовсе:** тень только тёмная.
- **Сайт живёт отдельно:** у каждой страницы свой `:root` со своими числами.

Уже перенесено (17.11.2026): тёмная тема UIEngine (`themes/soft.saltic`) сверена с языком
(цвета смысла одной светлоты, `panel` `#111723`, `raise` `#18202c`), а рисовальщик сам кладёт рамку
панели `rim`, свет сверху и сетку точек — у палитры с `lit`
(`registry/libraries/uiengine/draw/atoms.saltic`, `shapes.sheen`, `shapes.dots`).
Жителей для этого трогать не надо: панель — это `box` с `fill: panel`.
Темы — по файлу в `registry/libraries/uiengine/themes/`, программа выбирает
одну словом: `themes.named("soft" | "light" | "site" | "alchemy" | "armor" | "forest", screen)`.

Чтобы наследовалось автоматически, нужны три шага:

1. **Один файл токенов** (`registry/libraries/uiengine/draw/tokens.saltic`) —
   всё из раздела 1 по ролям; палитры UIEngine собираются из него, и из него
   же пишется `tokens.css` для сайта.
2. **Жители по ролям, а не числам:** размер — «подпись», «значение»,
   «название»; радиус — «клетка», «панель»; рисовальщик берёт числа из токенов.
3. **Недостающие компоненты жителями** (таблица раздела 3, где «нет»), плюс
   цветное свечение у атома.

После этого новая программа берёт жителей — и вид приходит сам, а правка
токена меняет весь стек разом.
