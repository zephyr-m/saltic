# Доменные ядра

Доменные ядра — это слой L3.

Они формализуют области знаний как библиотеки уровня языка, но не попадают в kernel и стандартную библиотеку.

## Черновые домены

```text
core.math
core.physics
core.chemistry
core.biology
core.geometry
core.logic
core.language
core.history
core.geography
core.economics
```

## Пример

```s
use core.math
use core.physics

skill main() {
    @force = physics.force(mass, acceleration)
    @area = math.triangle(a, b, c)
    out none
}
```

## Зачем это нужно

S должен помогать строить системы без постоянного поиска справочников.

Доменные ядра могут дать:

- формальные определения;
- распространённые константы;
- единицы измерения;
- проверенные операции;
- переиспользуемые модели предметных областей.

## Ограничение

L3 зависит от L2 и L1.

L1 и L2 не должны зависеть от L3.

## Практическое ограничение v0.1

L3 — большая идея, но не первая реализация.

Для v0.1 достаточно держать это как vision и начать максимум с:

- `core.math`;
- `core.logic`.

Остальные домены не должны мешать MVP языка.
