# События — ядро

**Решение автора, 13.11.2026.** События интерфейса — отдельный слой рядом с
JTML. JTML только описывает и рисует, слой событий только доставляет. В
разметке у атома есть лишь имя (`id`), действий в ней нет: логика живёт в
Saltic.

## Одно событие

Событие — не «что-то случилось», а **«у имени стало значение»**:

| поле | что это |
|---|---|
| `id` | имя: атом, устройство или такт |
| `number` | число |
| `text` | текст |
| `order` | номер — строгий порядок для повтора и второй машины |
| `time` | время |

Такт — то же изменение с именем `tick`. То же значение ещё раз — не изменение.
Последнее значение каждого имени ядро помнит, поэтому пропущенное событие не
страшно: последнее значение всегда правда.

| что | как ложится |
|---|---|
| нажатие | счётчик: `run` → 1, 2, 3; ни одно нажатие не теряется |
| поле, ползунок | `name` = «Зефир», `volume` = 57 |
| Enter в поле | счётчик `name.done` |
| перетаскивание | позиция атома — его значение |
| сочетание клавиш | программа объявила имя — счётчик |
| окно | `window.size`, счётчик `window.close` |
| сырой ввод | `key.space` = 1 / 0; `pointer.x` и `pointer.y` — парой с одним номером |

## Путь

```
железо ─► платформа ─► ядро событий ─► очередь ─► программа
          сырой ввод    попадание по       забирает по одному
                        раскладке,
                        изменение
```

Платформа отдаёт только сырое. Программа забирает изменения из очереди сама,
по одному; обработчиков, развешанных по узлам, нет.

## Слои

```
программа      ◄ клик, двойной клик, удержание, набор текста…
─────────────
ядро жестов    — верхнее: словарь жестов из изменений нижнего
─────────────
ядро событий   — нижнее: изменение и такт
```

Нижнее ядро — два вида изменений (значение и такт), его нельзя обойти. Верхнее
— ядро жестов: на нём работает интерфейс обычных программ и ОС. Жесты
выводятся из изменений нижнего и нового источника событий не добавляют.
Словарь жестов фиксированный: программа своих не задаёт, пополняет его только
автор. Мышь богатая: каждая кнопка и ось — своё имя в нижнем ядре
(`pointer.left`, `pointer.back`, `pointer.wheel`…), новый жест — новое правило
в верхнем. Состав словаря решит автор.

Канал не важен: изменение одно и то же, пришло ли оно от мыши, с другой машины
или от агента. Поэтому человек видит на экране всё, что делает агент, и
наоборот.
