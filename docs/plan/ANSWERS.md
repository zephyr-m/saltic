переезжает сюда под тем же номером: коротко суть вопроса, ответ и дата.

ответов до 06.11.2026 — в прежнем плане
[PLAN-1](../../.archive/docs/PLAN-1.md), раздел указан у ответа.
Новый ответ — сверху.

## Q-014. Как дробное число живёт в слове с меткой

Обычное значение — 64-битное слово с 3 битами метки, а `double` занимает
все 64 бита. Варианты были: сырое значение как у фиксированных типов
(ждёт 3а), объект в куче на каждое значение (медленно), урезанная
плавающая.

**Ответ 06.11.2026:** урезанная плавающая — 61 бит: `double` без трёх
младших битов мантиссы, на их месте метка. Около 15 десятичных знаков
вместо 16; дробные — обычные значения (группы, поля, параметры, `out`) без
3а. Заодно закрыто противоречие в прежнем плане: вид дробных — плавающие.
32-битные платы — отдельный вопрос.

## Q-013. Какие команды RV64 знает ассемблер

**Ответ 06.11.2026:** ассемблер и дизассемблер сразу знают весь RVA23
таблицей (I, M, A, F, D, C, Zba/Zbb/Zbs, Zicond, Zcb, Zfa, V…); кодоген
берёт команды по мере пользы: I и M, затем дробные, битовые и сжатые,
векторы — под матрицы. → PLAN-1 «Потом», «Каноническая машина»

## Q-012. Когда перевод RV32I → x86-64 уходит на пенсию

**Ответ 06.11.2026:** когда родной x86-64 на 64 битах сойдётся с RV64 по
выводу тестов. Ушёл 06.11.2026 в `.archive/x86_64_translation/` — ничего не
удалять, только в архив. → PLAN-1 «Каноническая машина», шаг 6

## Q-011. Что делать с 32-битными платами при каноне RV64

**Ответ 06.11.2026:** «два мира» — RV32I, Thumb-2, Xtensa: слово 4 байта и
число 29 бит, как раньше, больше — `NumberOverflow`; RV64 и x86-64 —
61-битное число. → PLAN-1 «Каноническая машина»

## Q-008. Какие дробные числа

**Ответ 04.11.2026:** плавающие (на x86-64 — SSE, на RISC-V — F/D); «почти
равно» — `~=` с точностью `NEAR`. → PLAN-1 «До заморозки синтаксиса», «Дробные числа»

## Q-007. Как получать вывод запущенной программы

**Ответ 04.11.2026:** два навыка — `process.capture([…])` отдаёт `code` и
`output` целиком после завершения, `process.lines([…])` — строки по одной,
пока ребёнок работает. → PLAN-1 «Инструменты», «Bash-скрипты → Saltic»

## Q-006. Где искать программу для запуска

**Ответ 04.11.2026:** сами, как терминал: имя без `/` — по папкам `PATH`,
первое найденное; с `/` — путь как есть; не нашлось — ошибка по имени
(`ProgramNotFound`). → PLAN-1 «Инструменты»

## Q-005. Форма запуска процесса

**Ответ 04.11.2026:** `process.run(["git", "status"]) -> код выхода` —
команда группой слов. Отвергнуты строка `"git status"`,
`run(программа, [аргументы])`, Box с выводом целиком, `process.shell`.
→ PLAN-1 «Инструменты»

## Q-003. Своя арена и настоящая память

**Ответ 04.11.2026:** разные имена — `arena.load8/16/32` и
`arena.store8/16/32` для своей арены (число-смещение), `mem.*` — только
`address`. Уточнение 06.11.2026: отдельного пути «в свою арену» в
рантайме нет — обе нынешние формы читают настоящую память. → PLAN-1 «До заморозки синтаксиса»
