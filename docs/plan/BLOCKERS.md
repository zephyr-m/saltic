# Блокеры

Что не даёт начать работу: недостающее решение автора или недостающая часть
системы. Сняли блокер — строку убираем, решение — в свой документ
(`ANSWERS.md`, канон, план). Записано 12.11.2026.

## 1. Хранилище «ключ → значение» — вторая модель памяти

Решено 08.11.2026 (`docs/language/MEMORY-MODEL.md`): память гибридная — регионы
для короткого, хранилище для долгого; `put` копирует внутрь, `get` — обратно в
регион вызывающего; перезапись ключа освобождает старое. Сначала своё у каждой
программы, общее на машину — позже. Первый потребитель — хранитель экрана агента
вместо `os/target/uefi_x86_64/screen/clay/cast.saltic`. Отдельной задачи в плане
нет: упомянуто только в отложенном «Куча растёт по запросу» (раздел 6).

Не можем начать — нужны решения:

1. Язык или библиотека: конструкция, которую понимает чекер, или модуль
   (вроде `core.store` с `put` / `get`).
2. Устройство внутри: список по номеру, хеш-таблица, своё.
3. Что может быть ключом: текст, число, любое значение.
4. Как долгий Box держит долгое: поле хранит ключ вместо значения — само,
   или программист кладёт в хранилище и держит в поле ключ.
5. Побеги: хранилище сразу заменяет таблицу побегов (в значении побега — ключ,
   а не адрес) или это второй шаг.

После ответов — исполнение: распределитель свободных кусков, тесты, перевод
`cast.saltic`.

## 2. APK — приложение на телефон

Не можем — нет частей системы:

1. ELF-библиотеки `.so` (компилятор умеет только самостоятельную программу).
2. Вызова чужого кода: окно, касания и поток в Android — функции системных
   библиотек, Saltic пока не зовёт функции не на Saltic.
3. Двоичного XML Android (манифест).
4. zip (CRC32 уже есть: PNG чеков, GPT на Acer).
5. Подписи APK v2: SHA-256, ECDSA, X.509. Обход — официальный `apksigner`
   (скачивает автор).
