## Q-047. Матрица: из чего она и как с ней работать

**К чему:** PLAN 3, «Матрица»; PLAN-1 «До заморозки» (решение 03.11.2026:
отдельный тип, навыки слоя `matrix.multiply(a, b)`, `matrix.transpose(a)`…,
`*` только для чисел; порядок — `words` → дробные → `core.matrix` → векторы).

Порядок решён до дробных; теперь дробные есть, и у шага `words` поплыл смысл.

1. **Чем заполнена матрица:** дробными (64 бита, как в языке), 32-битными
   плавающими (вдвое плотнее, как в нейросетях), целыми — или вид выбирается
   при создании?
2. **`words`:** «сплошная память 32-битных чисел, родственник `core.bytes`» —
   это целые (что отдаёт `get`: `u32`, `i32` или обычное число — на rv32i
   32 бита в обычное число не влезают)? Нужен ли он, если матрица — из
   дробных (тогда хранилище — 64-битные ячейки)?
3. **Навыки первого шага:** `matrix.new(rows, columns)`, `get`/`set`,
   `rows`/`columns`, `multiply`, `transpose`, `add` — так? Ошибки: размеры не
   сходятся — `MatrixShape`, индекс вне — `MatrixBounds`?
4. **Цели:** только 64-битные (как дробные) или и rv32i?

**Рекомендация:** 1 — дробные (один вид чисел в языке, точность для ИИ —
потом 32-битный вид); 2 — `words` для матрицы не нужен, хранилище —
64-битные ячейки внутри `core.matrix`; `words` — отдельно, когда понадобится
драйверам; 3 — так; 4 — только 64-битные.

## Q-001. Откуда тип параметра

**К чему:** 64-битные числа, путь 3, шаг 3а —
[RECON.md](RECON.md#3а-фиксированные-типы-выходят-из-навыка--04112026);
[PLAN-1](../../.archive/docs/PLAN-1.md), «Типы у параметров и результатов навыков» (решение
автора 03.11: чекер выводит типы сам, без подписей).

Чекер должен знать, что параметр `p` — `u32`, иначе выберет не ту арифметику.

- **Из мест вызова.** Тип параметра — тип того, что передают во всех
  вызовах; разные типы (то `u32`, то число) — ошибка. Требует обхода графа
  вызовов до неподвижной точки.
- **Из тела.** Тип — по тому, как параметр используют. Слабее: `out p` или
  передача дальше о типе ничего не говорят.

**Рекомендация:** из мест вызова, у параметра один тип; в ошибке — откуда
пришёл тип.
