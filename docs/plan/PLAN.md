## 1. Баги

- [ ] `file.read` у файлов /proc отдаёт пустую строку. 07.11.2026,
  `bootstrap/names.saltic`: `/proc/cpuinfo` прочитан как "" — размер файла
  берётся через lseek, а у /proc он 0. Обход — `cat`. Нужно: читать до конца,
  если размер 0.
- [ ] Агент после приёма большой программы не может перезагрузиться. 07.11.2026,
  агент 32 на Acer: принял агента 33 (1,5 МБ, `bay_kb` 1548), `install` записал
  его на диск, а `reboot` («перезагружаюсь через 5 секунд») четыре раза подряд
  падал на «память исчерпана», агент продолжал работу. Перезагрузка — руками.
  Нужно: путь перезагрузки без выделения памяти (или освобождать принятое после
  install).
- [ ] Удобство Acer — регрессия глазами пользователя (хайку, агент 34, 07.11.2026):
  - доска задач (tasks) уходит под правую панель: «Делаю» обрезана, «Готово» не видно;
  - при выходе из программы — «программа закончила работу, status 2» без пояснения;
  - `quit` у программы без сети (cube) — красное «нет команды quit», хотя Esc работает;
  - чат принимает только латиницу;
  - подсказки мелкие и серые (cube, доска), журнал слева на снимке не читается;
  - `screen` перекрывает журнал и строку `print`;
  - wire: подпись сверху прижата к краю экрана.
  Предложения: журнал слева прятать по клавише; вместо «status 2» — «закрыто (Esc)».

- [ ] Проверка тега в операторах и при входе в навык, пока чекер
  не выводит типы: `plus_one("abc")` → пустая строка. → аудит 03.11, топ-1; → Q-026
- [ ] Ошибка рантайма называет навык и строку (`GroupBounds` без места). → аудит 03.11, 4.3
- [ ] Компилятор пишет выход без права исполнения (`chmod +x` в 8 скриптах). → аудит 03.11, 4.4; → Q-027
- [ ] Два уровня проверок: `tests/` → канон, граничные случаи всех типов,
  недостающие случаи канона и ошибок парсера. → PLAN-1 «Надёжность»; аудит 03.11, ось 7, 9
  07.11.2026: ядро в каноне (`core_probe`: str, group, num, bits32, bytes,
  dict); 9 ошибок лексера и парсера — `errors/parser/`, `pick_branch_not_condition`
  — в `control`. Осталось: граничные случаи всех типов; 10 кодов из исходника не
  вызвать (3 нигде не выдаются, 2 — ветка `seed`, `unknown_statement`, 4 внутренних
  бэкенда) — им нужны тесты бэкенда или архив.
- [ ] `platforms` (qemu-virt, uefi, closure) — в `global-check` (принцип 5 TESTING).
- [ ] Фаззер (`soul/craft/fuzzer.saltic`).
- [ ] Вызов метода у поля-Box внутри метода его Box (`base.register(…)`, где
  `base` — поле): чекер молчит, компилятор падает «не найден навык для вызова».
  Обход — через локальную переменную (`@b = base`). → разведка 2а, 07.11.2026
- [ ] Запись в своё поле из метода Box (`total = total + amount` внутри `skill` в
  Box): чекер молчит, программа падает Segmentation fault. Обход — состояние во
  вложенном Box и запись через локальный псевдоним (`@s = stream; s.x = …`), как
  в `core.dict` и `core.process.Lines`. → разведка 4а, 07.11.2026
- [ ] **Решение автора 07.11.2026: программа не крутится молча.** Раз в 10 секунд
  любая программа обязана подать голос, где бы она ни была (компилятор, тест, ОС),
  — иначе зависание неотличимо от долгой работы. Повод: компилятор под rv32i
  минутами молча разбирал шрифт ОС в `just hosts`. Как гарантировать (рантайм,
  таймер платформы, сторож снаружи) — **решение**, отдельный вопрос.
