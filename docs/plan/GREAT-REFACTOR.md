# Великий рефакторинг и очередь до скорости

Решение автора 14.11.2026. Дорога языка, крупными этапами, строго по очереди:

1. **Память** — новая модель по разбору
   [MEMORY-KV-STUDY](../language/MEMORY-KV-STUDY-2026-11-14.md): хранилище,
   карантин, без побегов; запрет циклов ссылок; ограниченное худшее время у
   каждой операции. Сделано — релиз 300:82:281 «Ни 1 потерянного байта» (15.11.2026).
2. **Автомат, потом метроном** — последние фичи языка. Сначала автомат: он задаёт
   границы переходов, метроном встаёт на них (решение автора 15.11.2026):
   [METRONOME.md](../language/METRONOME.md),
   [STATE-MACHINE.md](../language/STATE-MACHINE.md). Сначала разбор открытых
   вопросов, решения автора, потом реализация.
3. **Великий рефакторинг** — не только автомат, вшитый в кодоген: весь сам
   язык прошивается автоматом.
4. **Оптимизация** — оптимизация по профилю и другие ускорялки (ниже).

Автомат и метроном оставлены на конец нарочно: раньше они мешали бы, а теперь
ложатся на чистую модель языка.

## Оптимизация

Перенесено из [PLAN-1](../../.archive/docs/PLAN-1.md), «Скорость» (мысли и
решения автора 03.11.2026).

- **Оптимизация по профилю (PGO) — вершина скорости вместо JIT.** Программа
  один раз запускается в режиме замера и записывает, что вызывается чаще и
  какие значения приходят; компилятор собирает её заново с этим знанием.
  Скорость почти как у JIT, но без прогрева, одинаково при каждом запуске и
  без кода, который пишет код на ходу — предсказуемо и доказуемо. Замер
  03.11.2026 (fib(40)): Saltic 2,28 с обгоняет обычные интерпретаторы (PHP
  3,27, Lua 4,91, Ruby 6,75, Python 8,8); впереди языки с JIT (LuaJIT 0,51,
  Node 0,77, Ruby+YJIT 0,91, PHP+JIT 1,11) и C (-O0 0,58, -O2 0,11).
  С автоматом профиль — это карта горячих переходов между состояниями (оценка,
  не решение).
- **JIT — только для разработки и отладки:** быстрый цикл «поправил —
  увидел» без полной сборки. В готовые программы не попадает: непредсказуем,
  тяжёл, код пишет код.
- Приёмы:
  - встраивание (inlining): тело маленького навыка — прямо на месте вызова,
    без вызова и без проверки ошибки после него;
  - анализ побега (escape analysis): Box или группа, не покидающие навык,
    живут на стеке, а не в куче (связь с регионами);
  - хвостовая рекурсия: вызов себя в конце навыка — обычный цикл, стек не
    растёт;
  - свёртка констант: `60 * 60 * 24` считает компилятор, в программе —
    `86400`;
  - выбрасывание мёртвого кода (шрифт на 4,5 МБ в каждой программе);
  - автовекторизация: цикл над числами — векторные команды (SSE/AVX, RISC-V
    V), 4–16 чисел за раз; для матриц и ИИ;
  - инкрементальная сборка: пересобирается только изменённое;
  - супероптимизация: перебор коротких последовательностей команд для горячих
    кусков, самая быстрая — доказуемо равная исходной.
