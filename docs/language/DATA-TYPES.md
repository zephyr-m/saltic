## Что значат незнакомые

- **Фиксированной ширины** — число ровно на 8, 16, 32 или 64 бита, как
  регистры железа. Нужно драйверам: `u8` — байт от 0 до 255.
- **Длинная арифметика** — числа любой длины без переполнения (`2^200`
  точно). Нужна для криптографии.
- **Кортеж** — несколько разных значений одной пачкой без имён полей:
  `(1, "а")`.
- **Перечисление с данными** — вариант, внутри которого свои значения:
  «Фигура» — либо `Круг(радиус)`, либо `Квадрат(сторона)`. Этим знаменит Rust.
- **Ошибка как значение** — ошибка возвращается как обычный результат, а не
  «выбрасывается». В Saltic — `error.Имя` и `rescue`.
- **Функция как значение** — функцию можно положить в переменную или
  передать другой функции: `x => x * 2`.
- **Обобщённые типы** — «список чего угодно» `Список<T>`: один код для
  списков чисел, строк и прочего.
- **Интерфейс** — договор «у типа есть метод `нарисовать`» без уточнения,
  какой это тип.

## Что видно по колонке Saltic

- Сильное — то, что делает код простым: `yes/no`, `none`, ошибки по имени,
  `Box` с умолчаниями, один список — группа. Нет двух способов сделать одно.
- Нет совсем: дробных, функций как значений, обобщённых типов, кортежей.
  Дробные и 64-битные целые — решение автора 02.11.2026 «будут»; дробные —
  плавающие (решение автора). 64-битные пришли с каноном RV64 (06.11.2026):
  на RV64 и x86-64 обычное число 61-битное, на 32-битных платах — 29 бит. Словарь —
  модуль ядра `core.dict` без нового синтаксиса (решение автора 03.11.2026):
  `dict.new()`, `dict.set` меняет на месте, `dict.get` (`UnknownKey`, если
  ключа нет), `dict.has`; ключ — только строка.
- Особняком — фиксированные типы (`u8…usize`, `bits32`, `address`): есть, но
  только внутри навыка; создаются только через `тип.from(…)` с `use core.тип`. Выпустить их в поля Box и результаты навыков — и
  драйверы станут заметно короче.
- PHP близок по духу: один `array` на всё — список, словарь, почти кортеж.
  Только PHP выбрал гибкость, а Saltic — простоту.
