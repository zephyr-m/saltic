# agent

`agent.*` — будущий слой для агентной разработки.

Это не часть базового языка и не стандартная библиотека первой необходимости.

## Назначение

S задуман как язык, удобный для человека и агента. Но агентный слой должен появляться после того, как язык уже умеет писать и запускать обычные программы.

Возможные модули:

```text
agent.task
agent.plan
agent.memory
agent.tool
agent.trace
agent.eval
agent.sandbox
agent.prompt
```

## Примеры будущих задач

- описать задачу;
- разбить задачу на шаги;
- сохранить локальную память;
- вызвать внешний инструмент;
- записать trace выполнения;
- проверить результат;
- ограничить sandbox.

## Правило

`agent.*` не должен превращать S в DSL только для агентов.

Обычный системный код должен оставаться обычным системным кодом.
