главное достижение

Компилятор собирает сам себя, байт в байт

Каждое изменение компилятора проходит три поколения. Второе и третье обязаны совпасть побайтово: если хоть один байт разошёлся, изменение не принимается.

исходник .saltic→ лексер→ парсер→ чекер→ кодогенерация→ RV32I→ ELF
RV32I→ перевод по инструкциям → x86-64→ ELF64 для Linux
загрузочный компилятор→ stage-1→ stage-2→ stage-3: stage-2 = stage-3
$ cmp stage-2/toolchain.elf stage-3/toolchain.elf fixed point: файлы совпадают, родной x86-компилятор выдаёт те же байты, что и под QEMU
как он выглядит

Мало слов, все явные

Код в стиле канона языка. Цикл, выбор, перехват ошибки и подстановка в строку — каждое своим словом, без скобочного шума.

use seed.io

skill react(agent, signal) {
    @energy = spend(agent.energy, signal.cost)
    @state = State.READY

    pick {
        (energy < 1) { state = State.EMPTY }
        { state = State.ACTIVE }
    }
    io.show("{agent.name}: энергия {energy}")
    out Agent { name = agent.name state = state energy = energy }
}

skill run(agent, signals) {
    @current = agent
    drum (signals) {
        current = react(current, beat) rescue |err| {
            io.show("rescue: ", err)
            current
        }
    }
    out current
}
drum

Цикл по группе или по числу шагов. Барабан бьёт, пока есть удары.

beat

Текущий удар: элемент группы или номер шага. Ручной счётчик больше не нужен.

pick

Первая подходящая ветка. Ветка без условия — только последней.

leave

Выход из ближайшего drum.

rescue

Перехват ошибки на месте, включая нехватку памяти.

"{имя}"

Подстановка в строку: сообщение пишется так, как его прочтут.

io.show

Чужой навык — только через короткое имя модуля из use seed.io. Один путь, длинный — ошибка.

как здесь работают

Правила, которые держат проект

Доказательство байтами

Рефакторинг принимается, только если программы совпадают побайтово под обе цели, RV32I и x86-64: just same, same-source.sh.

Автор решает, агенты делают

Архитектура, новые сущности и слова языка — только за автором. Агенты исследуют, исполняют и проверяют.

Явность и один путь

Нет not: отрицание пишется == no. На каждую вещь — один способ: к чужому модулю только модуль.навык.

Канон кода

Каждому файлу — владелец и ответственность. Не больше 500 строк, без utils и misc.

Ошибки по-русски

Парсер, чекер и компилятор говорят с автором на его языке. Все ошибки живут в каталоге errors.saltic, у каждой свой код, ни одна не молчит.

Релиз проверяет CI

Тег сверяется со счётом в VERSION, компилятор пересобирается и обязан совпасть с тем, что в git, тесты идут на всех хостах. О старте и итоге пишет бот в Telegram.

Куда прыгаем

64 бита и дробные числа

Решено: 64-битные целые и дробные числа будут. Графика на Acer показала цену 29 бит — трассировщик лучей превратился в подвиг. Форму выбирает автор.

Быстрее на x86

Работа с горячими регистрами напрямую, без промежуточных eax/ecx, и родной qemu-virt toolchain.

До заморозки синтаксиса

Типы у параметров, словари, переменное число аргументов. Потом синтаксис замирает, внутренности растут.
