## Шапки, вызвавшие сомнения

Всё ниже — [чтение], написано осторожно; стоит глянуть автору.

- `core/cpu.saltic`, `core/system.saltic` — смысл `firmware(piece)` /
  `call(hi, lo)` и SYSCALL_FIRMWARE восстановлен из `emit/host.saltic` и
  использования в `platform/firmware.saltic`.
- `core/mem.saltic` — две формы адреса (`address` + usize-смещение либо
  `[hi, lo]`) выведены из `fixed.saltic` и канона; `arena(piece)` — по
  `emit_mem_arena`.
- `soul/seed/io.saltic` — `key()`: «до 8 байт, сырой режим, Ctrl-C → код 130» по
  константам `emit/terminal.saltic`.
- `selfhost/toolchain.saltic` — «модули ищутся от текущей папки» (в коде
  `load_modules(path, ".")`).
- `checker/walk.saltic` — «область копируется на входе в блок» — упрощение кода.
- `abi/errors.saltic` — «системные 1…11» взято из SYSTEM_FIRST/LAST как есть.
- `compiler/state.saltic` — `emit_data/emit_writable/emit_blank` — пустые
  заглушки, так и написано; поля `lines/data/writable` похожи на мёртвый код.
- `emit/host.saltic` — «rt_platform_write/exit только для Linux» — вывод из того,
  что `append_runtime_common` их не включает.
- `emit/memory.saltic` — роли регистров s1/s2/s4/s5 по коду `rt_alloc`/`rt_region_exit`.
- `backend/x86_64/platform.saltic`, `uefi.saltic` — байты заглушек описаны по
  месту использования, не дизассемблированы.
- `machine/word.saltic` — «to_number до 2^28» по проверке `b3 > 15`.
- `os/drivers/timer` — «CLINT mtime 0x200BFF8» по адресу `[512, 0] + 49144`;
  `framebuffer`/`fw_cfg`/`virtio_mmio` — hex-адреса пересчитаны из пар hi/lo;
  «XRGB» для ramfb — из байтов "42RX".
- `os/fonts/spleen.saltic` — «161 глиф, порядок ASCII, Ё, А–я, ё» по
  `font_glyph_index` в `drivers/font.saltic`.
- `uefi_x86_64/platform/clock.saltic` — «пояс зашит +5 часов», «високосный —
  только делимость на 4»: так в коде, но пояс автор может считать настройкой.
  `platform/uefi.saltic` — Clock назван «UTC» [предп.].
- `uefi_x86_64/screen/glyphs.saltic` — порядок глифов по `lettering.glyph_index`;
  «сгенерировано tools/glyphs.py» по тексту скрипта.
- `uefi_x86_64/storage/disk.saltic` — «раздел EFI 512 МБ», «диск больше 10 ГБ» —
  из констант.
- `uefi_x86_64/drivers/usb.saltic` — навык `protocols` про диск, не про USB;
  описан как есть.
- `uiengine/fonts/generated/*` — генератор, веса и шрифты (Noto Sans / Mono) из
  `FACES` в `tools/fonts.py`; формат таблиц — по тому, как читает `fonts.saltic`.
  `demo/generated/*_jtml` — имена страниц по `monitor.TABS`.
  `components/desktop/wallpaper` — «под 1366×768» из координат ANCHORS.
  `demo/monitor.saltic` — часть чисел «Пульта» названа заглушками (зашиты в коде).
- `craft`: заготовки `hardware/pci, uart, virtio` — в шапке сказано, где
  рабочий код сейчас (`os/target/uefi_x86_64`, `os/drivers`) — если лишнее, убрать.
  В `json/number, text, writer`, `json_rpc/decoder`, `uiengine/shapes, table,
  drop`, `os/apps/space, snake, colony` внутренние помощники сведены в одну строку
  «Внутри: …» — решить, считать ли их публичными.
- `tests/fixtures/memory-type.saltic` — шапка говорит «не собирается»; вывод `cc`
  до и после одинаков (`type_mismatch|0|0|…`) [запуск].
