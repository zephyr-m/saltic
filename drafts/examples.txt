ТИПЫ ДАННЫХ
- Умная типизация: вывод типа при первом присваивании
- Box: контейнер для данных (заменяет struct и null/none)
- enum: перечисление (без изменений)
- union: tagged union (без изменений, tagged по умолчанию)
- Массивы: i32[1, 2, 3]

ПЕРЕМЕННЫЕ
- @x: объявление переменной (ждёт первого присваивания)
- x = 10: первое присваивание фиксирует тип
- Константы: MaxSize = 100 (большая буква, без ключевого слова)

ФУНКЦИИ
- skill: объявление функции (вместо fn)
- out: возврат значения (вместо return)
- Любая функция может вернуть ошибку (без !)

ВЕТВЛЕНИЕ
- (условие) { ... }: простое условие (вместо if)
- (enum) { .A => ..., .B => ... }: множественный выбор (вместо switch)

ЦИКЛЫ
- drum { ... }: бесконечный цикл с ручным stop
- drum (@i = 5) { ... }: цикл со счётчиком
- drum (value in arr) { ... }: цикл по коллекции

ОБРАБОТКА ОШИБОК
- rescue |err| { ... }: явная обработка ошибки (вместо catch)
- try: проброс ошибки выше
- Автоматический лог: все необработанные ошибки → yametekudasai.log
- yametekudasai.log: файл лога с именем файла, строкой, ошибкой
- Последняя строка лога: Yametekudasai xN (счётчик ошибок)

ИМПОРТ
- use: подключение модулей (вместо @import)

ИГНОРИРОВАНИЕ
- _: игнорирование переменной (без изменений)

УБРАНО
- defer: удалён
- for/while: заменены на drum
- if/switch: заменены на скобки
- struct/null: заменены на Box/none
- fn/return: заменены на skill/out
- catch: заменён на rescue
