# Верстак

Инструменты разработки, которыми пользуются автор и агенты. В релизный пакет
не входят. Промежуточные файлы и логи пишутся в `.cache/build/workbench/`.

| Скрипт | Что делает |
|---|---|
| `limits.saltic` | На Saltic, вместо `limits.sh`. Лимиты канона архитектуры: до 512 строк кода в рукописном `.saltic` и до 32 строк шапки. Известные нарушения — в `limits-known.txt` (правит автор): им нельзя расти; падает на новом или выросшем. Вызывается `just limits` и первым шагом `global-check` |
| `global-check.sh` | Глобальная проверка любого изменения: лимиты канона, самосборка с fixed point трёх целей (rv64 — эталон в git, x86-64, rv32i — вторая сверка) и паспортами в `bootstrap/`, время самосборки против прошлого прогона, тесты на rv32i с полным логом в `global-check.log`. Вызывается `just global-check` |
| `hosts.saltic` | На Saltic (core.process), вместо `hosts.sh`. Перед релизом: тесты на x86-64 прямо на процессоре (родной `x86_64`), тесты ОС (`os`: jtml, tasks, panels, mrpc), тесты компилятором RV64 под `qemu-riscv64` (группы с жёсткой целью — своей), затем qemu-virt (графика), x86-64 UEFI и rv32i closure; лог в `hosts.log`. Вызывается `just hosts` и CI релиза |
| `stamp.saltic` | Время `[ЧЧ:ММ:СС]` у каждой строки вывода скриптов: `bootstrap/stamp.sh` собирает его в `.cache/build/workbench/stamp` и пропускает через него вывод; без часов в компиляторе — прежний цикл bash. Провал команды — код 1 и строка «ошибка: StampedFailed» |
| `golden.py` | ⚠️ устарел (см. PLAN, «Рефакторинг»): пересчитывал побайтовые эталоны машинного кода, когда они лежали одним файлом `translation.saltic`; сейчас они в `soul/seed/tests/machine/runtime_bytes/tr_*.saltic` (бывшая `translation/`) |
| `perf.sh <компилятор.elf> <исходник>` | Профиль программы под QEMU через `perf`: сколько времени уходит на сам QEMU и на какие функции Saltic |
| `same.sh [исходники…]` | Проверка рефакторинга компилятора: текущие исходники, собранные компилятором с полки `bootstrap/` и новым stage-1 под rv64, x86_64 и rv32i, должны совпасть побайтово; плюс набор ошибок канона. Оба компилятора работают родными x86-версиями. Вызывается `just same` |
| `same-source.sh` | Проверка правки исходников без изменения смысла: все программы (toolchain, канон, тесты, образ ОС) собираются одним компилятором из HEAD и из рабочего дерева и сравниваются побайтово |
| `x86-encoder-golden.sh [--print]` | Эталоны кодировщика x86-64: каждую команду из `tests/x86-encoder.saltic` собирает GNU `as` и сверяет байты с тестом; `--print` печатает байты `as` для новых эталонов |

Тяжёлые проверки (`global-check.sh`, `hosts.saltic`, `same.sh`, `same-source.sh`) запускает автор.
