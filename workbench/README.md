# Верстак

Инструменты разработки, которыми пользуются автор и агенты. В релизный пакет
не входят. Промежуточные файлы и логи пишутся в `.cache/build/workbench/`.

| Скрипт | Что делает |
|---|---|
| `step.sh` | Проверка изменения компилятора: самосборка с fixed point, замер скорости против прежнего `compiler.elf`, `just fast` с полным логом в `step.log` |
| `rest.sh [кейсы…]` | Прогоняет проверки по одной и печатает короткий итог каждой; логи в `rest-<кейс>.log` |
| `golden.py` | Пересчитывает побайтовые эталоны машинного кода в `soul/seed/tests/machine/translation.saltic` после намеренного изменения кодогенерации |
| `perf.sh <компилятор.elf> <исходник>` | Профиль программы под QEMU через `perf`: сколько времени уходит на сам QEMU и на какие функции Saltic |
| `same.sh [исходники…]` | Проверка рефакторинга без изменения смысла: текущие исходники, собранные старым `compiler.elf` и новым stage-1, должны совпасть побайтово; плюс набор ошибок канона |
| `native-compiler.sh` | Переводит компилятор в x86-64 и сравнивает его вывод с компилятором под QEMU |

Тяжёлые проверки (`step.sh`, `rest.sh`, `native-compiler.sh`) запускает автор.
