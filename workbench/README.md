# Верстак

Инструменты разработки, которыми пользуются автор и агенты. В релизный пакет
не входят. Промежуточные файлы и логи пишутся в `.cache/build/workbench/`.

| Скрипт | Что делает |
|---|---|
| `global-check.sh` | Глобальная проверка любого изменения: самосборка с fixed point и паспортами в `bootstrap/`, время самосборки против прошлого прогона, тесты на rv32i с полным логом в `global-check.log`. Вызывается `just global-check` |
| `hosts.sh` | Перед релизом: тесты на x86-64 прямо на процессоре (перевод, затем родной `x86_64-native`), затем qemu-virt (графика), x86-64 UEFI и rv32i closure; лог в `hosts.log`. Вызывается `just hosts` и CI релиза |
| `golden.py` | ⚠️ устарел (см. PLAN, «Рефакторинг»): пересчитывал побайтовые эталоны машинного кода, когда они лежали одним файлом `translation.saltic`; сейчас они в `soul/seed/tests/machine/translation/tr_*.saltic` |
| `perf.sh <компилятор.elf> <исходник>` | Профиль программы под QEMU через `perf`: сколько времени уходит на сам QEMU и на какие функции Saltic |
| `oracle.sh [исходники…]` | Оракул родного x86-64: каждая программа собирается stage-1 под `x86_64-translation` и `x86_64-native`, запускается на обеих; stdout и код выхода обязаны совпасть, размеры образов печатаются. Пока полка не знает родной цели — `SALTIC_BOOTSTRAP_COMPILER=<свежий stage-1>` |
| `same.sh [исходники…]` | Проверка рефакторинга компилятора: текущие исходники, собранные компилятором с полки `bootstrap/` и новым stage-1 под rv32i, x86_64 и x86_64-native, должны совпасть побайтово; плюс набор ошибок канона. Оба компилятора работают родными x86-версиями. Вызывается `just same` |
| `same-source.sh` | Проверка правки исходников без изменения смысла: все программы (toolchain, канон, тесты, образ ОС) собираются одним компилятором из HEAD и из рабочего дерева и сравниваются побайтово |
| `x86-encoder-golden.sh [--print]` | Эталоны кодировщика x86-64: каждую команду из `tests/x86-encoder.saltic` собирает GNU `as` и сверяет байты с тестом; `--print` печатает байты `as` для новых эталонов |

Тяжёлые проверки (`global-check.sh`, `hosts.sh`, `same.sh`, `same-source.sh`) запускает автор.
