# Верстак

Инструменты разработки, которыми пользуются автор и агенты. В релизный пакет
не входят. Промежуточные файлы и логи пишутся в `.cache/build/workbench/`.

| Скрипт | Что делает |
|---|---|
| `global-check.sh` | Глобальная проверка любого изменения: самосборка с fixed point и паспортами в `bootstrap/`, замер скорости против прежнего компилятора, `just test` с полным логом в `global-check.log` |
| `golden.py` | Пересчитывает побайтовые эталоны машинного кода в `soul/seed/tests/machine/translation.saltic` после намеренного изменения кодогенерации |
| `perf.sh <компилятор.elf> <исходник>` | Профиль программы под QEMU через `perf`: сколько времени уходит на сам QEMU и на какие функции Saltic |
| `same.sh [исходники…]` | Проверка рефакторинга без изменения смысла: текущие исходники, собранные компилятором с полки `bootstrap/` и новым stage-1, должны совпасть побайтово; плюс набор ошибок канона |
| `same-source.sh` | Проверка правки исходников без изменения смысла: все программы (toolchain, канон, тесты, образ ОС) собираются одним компилятором из HEAD и из рабочего дерева и сравниваются побайтово |

Тяжёлые проверки (`global-check.sh`, `same.sh`, `same-source.sh`) запускает автор.
