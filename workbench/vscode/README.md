# Saltic для Visual Studio Code

Расширение добавляет базовый визуальный слой Saltic:

- распознавание файлов `.saltic`;
- подсветку актуального синтаксиса через TextMate;
- парные скобки и автоматические отступы;
- переход к определению: Ctrl+щелчок или F12 по имени навыка, Box, enum, константы
  (`extension.js` спрашивает `lens goto` — тот же `workbench/agent/lens/jump.saltic`, что у SalticIDE;
  нужен собранный lens — `just lens-serve`), по пути в `use` — открыть файл модуля;
- иконку языка и файловую тему Saltic Icons;
- цветовую тему «Saltic Тема 1» в двух видах — светлую (`themes/saltic-theme-1-light.json`,
  акцент бирюзовый) и тёмную (`themes/saltic-theme-1.json`, акцент коралловый) — как окно
  SalticIDE (`docs/site/public/IDE.html`): цвет несёт смысл, определения — жирным; значок файла —
  стрелки в кружке, кружок контрастен теме.

Установка ссылкой: `ln -s "$PWD" ~/.vscode/extensions/saltic.saltic-language-0.5.0`,
затем `Ctrl+K Ctrl+T` → «Saltic Тема 1 · светлая» или «Saltic Тема 1».

## Локальная проверка

Открой каталог расширения в VS Code:

```bash
code workbench/vscode
```

Нажми `F5`, затем открой `soul/toolchains/qemu_virt/checks/smoke.saltic` в окне Extension Development Host.

## Граница

Это лексическая подсветка: поле справа от `=` и переменную она не различает (`name = "pip"` в Box
красится как переменная) — это умеет только чекер. Переход к определению ищет по имени и месту слова, без типов: одинаковые имена у разных
хозяев покажутся списком (сначала свои и из use). Диагностика и автодополнение появятся вместе
с языковым сервером.
