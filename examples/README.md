# Examples

## Apps

- [family ledger](apps/family-ledger/README.md) — маленький финансовый журнал
  семьи на S.

Примеры разделены по назначению:

- `user/` — обычные пользовательские программы на S. Здесь используется `use core`, прямой `host.*` запрещён.
- `canonical/` — эталонные примеры целевого стиля языка. Файлы `*.core.s` используют только `core.*`.
- `bootstrap/` — низкоуровневые примеры текущего bootstrap/runtime слоя. Здесь `host.*` допустим.

Если пример выглядит как код, который должен писать пользователь S, его место в `user/` или `canonical/`, а не в `bootstrap/`.
