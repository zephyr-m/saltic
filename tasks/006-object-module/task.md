# 006 object module

Вынести объект в отдельный файл со своими состояниями, свойствами и реакцией на событие.

Задача проверяет `Object module v0`: объектный лист импортируется через `use objects.player`.

Нужно:

- в `objects/player.s` описать `PlayerState`, `Point`, `Player`, `Move`;
- там же описать `react(player, move)`;
- в `solution.s` импортировать объектный модуль;
- создать игрока и событие движения;
- получить следующее состояние через `react`;
- вывести имя, состояние и позицию.

Ожидаемый вывод:

```text
PLAYER
PlayerState.MOVED
6,4
```
