# 009 laboratory sandbox loop

Проверить песочницу как поток входов, а не ручной сценарий.

Задача не добавляет реальный UI. Вместо этого используется заранее записанная группа `Input`, которая имитирует действия игрока.

Идея:

- программа не знает заранее "сюжет";
- программа получает вход;
- `dispatch(lab, input)` применяет правила;
- `render(lab)` показывает состояние после каждого шага.

Сцена:

- в лаборатории есть ключ;
- есть замок;
- есть дверь;
- игрок может вставить ключ в замок;
- повернуть замок;
- открыть дверь.

Ожидаемый вывод:

```text
lock: LockState.INSERTED
door: DoorState.CLOSED
lock: LockState.UNLOCKED
door: DoorState.CLOSED
lock: LockState.UNLOCKED
door: DoorState.OPEN
```
