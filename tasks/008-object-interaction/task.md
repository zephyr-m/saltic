# 008 object interaction

Проверить взаимодействие двух объектных модулей.

Задача не добавляет новый синтаксис. Она проверяет, что несколько object modules могут работать вместе:

- `objects/player.s` описывает игрока;
- `objects/door.s` описывает дверь;
- игрок получает ключ;
- дверь открывается только если событие содержит ключ.

Ожидаемый вывод:

```text
PLAYER
PlayerState.HAS_KEY
DOOR
DoorState.OPEN
```
