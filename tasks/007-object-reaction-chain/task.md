# 007 object reaction chain

Проверить объектный автомат на цепочке событий.

Задача не добавляет новый синтаксис. Она проверяет, что `Box`, `Group`, `drum` и `Object module v0` уже могут описать:

- объект с состоянием;
- события объекта;
- реакцию объекта на событие;
- последовательное применение событий;
- запрет перехода после `LOCKED`.

Сценарий:

1. Игрок стартует в точке `5,4`.
2. Событие `Move(1,0)` двигает его в `6,4`.
3. Событие `Move(0,1)` двигает его в `6,5`.
4. Событие `Lock` переводит его в `LOCKED`.
5. Событие `Move(10,0)` больше не меняет позицию.

Ожидаемый вывод:

```text
PLAYER
PlayerState.LOCKED
6,5
```
