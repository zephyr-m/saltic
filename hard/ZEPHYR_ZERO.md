# ZephyrZero v0

Первый законченный прибор Zephyr: небольшой автономный калькулятор, а не компьютер
общего назначения.

```text
кнопки → стикеры → Logos → арифметический протокол → цифры → свет
```

## v0

- беззнаковые числа `0..999`;
- операции `+`, `-`, `×`, `÷`;
- вычитание насыщается на нуле;
- деление возвращает частное и остаток;
- деление на ноль возвращает `valid = no`;
- вычислительный набор Logos: `A`, `B`, `RESULT`, `TEMP`;
- внешние части: кнопки, формирователь стикеров и цифровой индикатор.

`zephyr-zero.s` — первая эталонная программа. Пока она исполняется высокоуровневой
S VM; следующим слоем станет компиляция тех же единичных шагов в сеть Logos v0.
