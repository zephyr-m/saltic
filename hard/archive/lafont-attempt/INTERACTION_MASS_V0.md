# Interaction Mass v0

Первый исполняемый эксперимент вычислительной массы поверх неизменённой Logos v0.

## Масса

Используются ровно 16 Logos:

```text
0..6    графовый агент A
7..13   графовый агент B
14      свободная масса
15      двоичная граница DONE
```

Каждый графовый агент представлен семью счётчиковыми Logos:

```text
TYPE STATE PRINCIPAL LEFT RIGHT LOCK PAYLOAD
```

Начальное состояние содержит два агента `ε`, соединённых главными портами.

## Первое правило

```text
ε >< ε  →  free + free
```

Один входной стикер `DEC` запускает правило. Каждый непустой счётчик уменьшает себя и
возвращает `DEC` себе. Zero-реакция передаёт тот же стикер следующему полю. После
очистки четырнадцатого поля испускается `HALT` в двоичную границу `DONE`.

Ни симулятор, ни соседняя клетка не присваивают счётчикам значения напрямую во время
редукции. Все изменения после конфигурации происходят только в `Logos.step()` через
66-битные стикеры.

## Что эксперимент доказывает

- группа простых Logos может представлять один графовый агент;
- структура агента может быть переписана протоколом `DEC/zero`;
- ход вычисления переносится единственным стикером без общего PC;
- освобождение графовой пары выражается изменением самой вычислительной массы;
- завершение наблюдается как двоичное состояние отдельной границы.

Это физический протокол первого канонического правила `εε`. Эксперимент пока не
доказывает динамическое обнаружение активной пары, остальные пять правил или
параллельную редукцию. Связь первой пары скомпилирована в таблицы реакций заранее.
