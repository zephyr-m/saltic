# Образ ESP

- **Расширение:** `.bin`.
- **Где запускается:** ESP32, ESP32-S3 через esptool.
- **Состояние:** `image.ram` / `image.app` — заголовок 8+16, сегменты IRAM и DRAM, XOR-сумма. SHA-256 нет: ПЗУ её не проверяет.
- **Заметка:** на DevKit платформа печатает `S`, программа `smoke` — «привет, ESP32».
