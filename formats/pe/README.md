- **Расширение:** `.efi`, `.exe`.
- **Где запускается:** прошивка UEFI; Windows.
- **Состояние:** ✅ `.efi` есть, но не здесь: `soul/seed/selfhost/compiler/backend/x86_64_native/pe.saltic`. Переедет сюда. ⬜ `.exe` — почти даром.
