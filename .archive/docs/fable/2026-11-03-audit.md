## Топ-10

1. **Тип через параметр теряется, а рантайм молчит.** `skill plus_one(v) { out v + 1 }`:
   `plus_one("abc")` → пустая строка, `plus_one(yes)` → `yes`, `less("a", "b")` → `yes`,
   `p.x = "text"` через параметр проходит, потом `p.x + 1` → мусор. Чекер
   даёт параметру тип `unknown` (`checker/walk.saltic:512`), результату
   пользовательского навыка — тоже (`checker/types.saltic:177-203`), а `+ − * / < >`
   в коде складывают слова без проверки тега (`compiler/codegen/emitters.saltic`,
   `emit_checked_word`). Одинаково на обеих целях. [запуск] — ось 3.
2. **Ввод и платформа не переносимы.** Одна программа на трёх целях ведёт себя
   трояко: `io.file.read` — Linux читает, UEFI отдаёт `File` (заглушка
   возвращает −38), qemu-virt убивает программу ловушкой; `io.key` — Linux
   termios, UEFI — один байт и стрелки как `escape`, qemu-virt — ввода нет;
   `cpu.wait()` — Illegal instruction и на Linux x86, и под `qemu-riscv32`;
   UEFI теряет код выхода (всегда 0) и печатает `?` вместо кириллицы. Всё это
   живёт в байтах без исходника (`backend/x86_64_translation/{platform,uefi}.saltic`),
   я их дизассемблировала. [запуск, чтение] — ось 10.
3. **Имена вариантов enum глобальны на всю программу, включая модули.** `READY`
   в `State` главной программы и в `Mode` модуля → `duplicate_enum_variant`
   (`checker/top_level.saltic:76-86`, ключ `names.variant_key` без модуля —
   `checker/names.saltic:41-43`). Для ОС из десятков модулей это запрет
   на `IDLE`/`READY`/`NONE` больше чем в одном месте. [запуск] — оси 1, 3.
4. **Чекер молчит там, где должен ругаться:** пропущенный вариант в
   сопоставлении enum (`walk.saltic:449-483` — только дубли); `==` разных
   известных типов (`1 == "1"`, `yes == 1`, `none == 0` — `types.saltic:243-247`);
   условие любого типа (`(7) { … }` — истина, `("text") { … }` — истина,
   `walk.saltic:431-435`); метод по имени с другой арностью (`thing.has()`
   зовёт `has(value)` без аргумента — `compiler/functions.saltic:175-183`).
   Сопоставление enum к тому же не выражение: `.LIGHT => "light"` молча
   выбрасывается. [запуск] — оси 1, 3.
5. **Арена без реестра.** Четыре слоя кладут данные по голым смещениям от
   `firmware.arena(base)`: `rtl8111` TX_BUFFER=4096/RX_BUFFERS=8192 и
   `qca9377/rings` SOURCE_RING=4096/DESTINATION_RING=8192 — одни адреса;

   `bytes`, клавиатуры; `GroupBounds`, `DivisionByZero`, `StringBounds`, строки

10. **Группа-константа — это код.** Литерал группы компилируется в команды
    (`compiler/codegen.saltic:185-200`: `rt_alloc` + запись каждого

`uefi.saltic`.
