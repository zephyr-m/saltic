# Family graph

Небольшая графовая память на Saltic.

Память хранит только узлы и направленные рёбра. Семейная модель записывает два
вида фактов:

- parent — направленная связь от родителя к ребёнку;
- spouse — одно симметрично читаемое ребро между людьми.

Братья, сёстры, дети, предки, бабушки, дедушки и кузены в память отдельно не
записываются. Они выводятся из исходных связей обходом графа.

Пример намеренно допускает несколько супружеских связей и сводное родство:
граф не навязывает семье форму дерева.

Запуск:

    just run family-graph/main.saltic
