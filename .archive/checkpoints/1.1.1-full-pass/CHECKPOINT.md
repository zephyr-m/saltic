# Saltic 1.1.1 — полный проход

Замороженная контрольная точка контура JavaScript ↔ Saltic и независимого
bootstrap. Исходное состояние репозитория: коммит `5d283b3`; bootstrap
зафиксирован коммитом `998100f`.

Содержимое этой папки самодостаточно относительно исходников проекта и не
должно развиваться вместе с основным языком. Оно предназначено для проверки
исторического паритета и возврата к известной границе.

Полная проверка из этой папки:

```sh
just test
```

Внешние инструменты: Bash, Node.js, Nix, QEMU и GCC для RV32.
