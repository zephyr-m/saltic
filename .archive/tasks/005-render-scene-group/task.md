# 005 render scene group

Смоделировать один текстовый кадр цифрового мира, где объекты сцены лежат в группе.

Это продолжение `004-render-frame`: теперь сцена не должна вручную вызывать `print_object` для каждого объекта.

Нужно:

- описать `Point`, `Frame`, `Camera` и `Object` через `Box`;
- создать группу объектов сцены;
- пройти по группе через `drum`;
- для каждого объекта посчитать видимость;
- вывести объект как `visible` или `hidden`.

Индекс шага должен быть явным состоянием программы, а не отдельной формой цикла.

Ожидаемый вывод:

```text
frame: 20x10
camera: 0,0
PLAYER visible at 5,4
LIGHT visible at 2,2
WALL hidden at 10,4
```
