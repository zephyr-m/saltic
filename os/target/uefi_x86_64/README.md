# UEFI x86-64

Летопись первого вечера на железе, с фотографиями: [docs/history/2026-11-01.md](../../../docs/history/2026-11-01.md).

Saltic на ноутбуке без Linux: программа собирается как UEFI-приложение
(PE32+) и грузится прошивкой с флешки.

| Файл | Что делает |
|---|---|
| `hello.saltic` | первая программа: текст на экране и одно нажатие |
| `firmware.saltic` | общая основа: физические адреса, чтение и запись памяти, таблицы UEFI и ACPI, ECAM, поиск устройства PCI |
| `pci.saltic` | перечисление устройств PCI: системная таблица UEFI → ACPI RSDP → XSDT → MCFG → ECAM, обход всех шин; не выходит, пока ноутбук не выключат |
| `rtl8111.saltic` | драйвер Ethernet Realtek RTL8111: найти карту, сбросить, кольца дескрипторов в арене, дождаться линка; `send` кадра, `received`/`read_frame`/`release` для приёма. QEMU эту карту не эмулирует — проверка только на железе |
| `net.saltic` | сеть на группах байтов: Ethernet, ARP (ответ «10.0.0.2 — это я»), IPv4 с контрольной суммой, UDP; проверяется на Linux |
| `agent.saltic` | приёмник команд на 10.0.0.2:5555: `help`, `info`, `pci`, `mem <адрес> [байт]`, `echo`, `upload <байт>`, `check`, `run`; отвечает на ARP и по-русски (экран Acer — по-английски: у прошивки нет кириллицы); куски программы принимает на порт 5556 в арену и запускает её через прошивку |
| `uefi.saltic` | таблицы прошивки на Saltic через `firmware.call`: консоль (`wide_console` — самый большой текстовый режим), загрузка и запуск образа (`start_image`) |
| `graphics.saltic` | графика прошивки (GOP): найти протокол, размер экрана, формат пикселя, длина строки, адрес кадрового буфера; `fill` — прямоугольник прямо в видеопамять |
| `glyphs.saltic` | Spleen 8×16, 12×24, 16×32 с кириллицей — строка шестнадцатеричных цифр на букву; генерируется `tools/glyphs.py` из `os/fonts/spleen.saltic` (так программа весит 0,7 МБ, а не 5,2: компилятор не выбрасывает неиспользуемые размеры) |
| `lettering.saltic` | свои буквы в видеопамять: разбор UTF-8 из байтов, `paint_bytes`, `paint_text` |
| `files.saltic` | файлы через прошивку: все тома и диски (`volumes`, с `ConnectController` ко всем устройствам), каталоги, создание папок и файлов, `install` — записать принятую программу в `\EFI\BOOT\BOOTX64.EFI` на несъёмном томе |
| `disk.saltic` | разметка диска с нуля: защитный MBR, GPT (две копии, CRC32 — прошивкой), раздел EFI 512 МБ, FAT32; сектора собираются чистыми навыками и проверены на Linux (`sgdisk -v`, `fsck.fat`, `mtools`) |
| `spider.saltic` | маскот Saltic — паучок-скакун крупными пикселями справа под часами; маленькая программа для `upload … --run` рядом с агентом |
| `clock.saltic`, `parse.saltic` | время (UTC+5, полночь, конец месяца) и разбор чисел из команд — вынесены из агента |
| `feed.saltic` | лента на экране агента: команда серым со временем и адресом, под ней ответ (до 24 строк) |
| `usb.saltic` | USB через прошивку (`UsbIo`): `usb` — интерфейсы с VID:PID, классом и названием; `protocols N` — какие протоколы висят на диске N |
| `camera.saltic` | `camera` — описание конфигурации камеры `0408:a030`: форматы (MJPEG, YUYV), кадры, точки потока |
| `reply.saltic` | трубка для программ: `reply.finish(текст)` завершает программу через `Exit` с `ExitData`, агент пересылает текст по сети и на экран |
| `visitor.saltic` | маленькая программа для проверки `upload`: печатает приветствие и возвращается к агенту |
| `tools/listen.py` | «ухо» на проводе: печатает все кадры на интерфейсе (`sudo python3 tools/listen.py eno1`) |
| `tools/talk.py` | сырой разговор без ARP: раз в секунду шлёт `ping N` и печатает ответы (`sudo python3 tools/talk.py eno1`) |
| `tools/say.py` | одна команда агенту без root: `python3 tools/say.py info` (нужен адрес 10.0.0.1 на `eno1`) |
| `tools/glyphs.py` | пересобрать `glyphs.saltic` из `os/fonts/spleen.saltic` |
| `tools/shot.py` | снимок экрана Acer в PNG: `python3 tools/shot.py shot.png` (683 × 384, кусками по 1024 байта с повтором) |
| `tools/snippet.py` | кусок Saltic на Acer за ~1,3 с: `python3 tools/snippet.py '@x = 2 + 2\nout "x = {x}"'` — оборачивает в программу, собирает (`SALTIC_COMPILER` или полка), заливает, запускает, печатает ответ |
| `tools/snippets/` | готовые куски для `snippet.py -f`: `smbios.saltic` — BIOS, плата, процессор, планки памяти; `bgrt.saltic` — логотип из ACPI BGRT на экран |
| `tools/upload.py` | залить программу агенту и, с `--run`, запустить: `python3 tools/upload.py visitor.efi --run`; куски по 1024 байта с подтверждением, сверка суммы |
| `build.sh` | собирает `EFI/BOOT/BOOTX64.EFI` и папку образа флешки |
| `run.sh` | запускает собранное в QEMU x86-64 с прошивкой OVMF; `--check` — без окна, жмёт клавишу и ждёт «Bye!» (так его зовёт `tests/run.sh uefi`) |

Цель компилятора — `x86_64-uefi`. Образ — одна секция PE32+: таблица
переходов, регистры, переведённый код, точка входа и память гостя.
Системные вызовы идут в прошивку: вывод — `ConOut->OutputString`,
клавиша — `ConIn->ReadKeyStroke`, выход — возврат в прошивку.

## Флешка

1. Собрать: `bash os/target/uefi_x86_64/build.sh` — папка образа
   `.cache/build/uefi_x86_64/image`.
2. Проверить в QEMU: `bash os/target/uefi_x86_64/run.sh`.
3. Флешку отформатировать в FAT32 (`sudo mkfs.vfat -F 32 /dev/sdX1`,
   где `sdX1` — раздел флешки, проверить по `lsblk`), смонтировать и
   скопировать туда папку `EFI` из образа:
   `sudo cp -r .cache/build/uefi_x86_64/image/EFI /mnt/`.
4. На ноутбуке: Secure Boot выключен, загрузка с USB в режиме UEFI.
   Прошивка сама найдёт `EFI/BOOT/BOOTX64.EFI`.

## Сведения о прошивке

`core.cpu.firmware(кусок)` — системный вызов 500 в прослойке UEFI. Кусок 0–3 —
16-битные части базы гостевой памяти (`r14`: гостевой адрес `x` — это
физический `r14 + x`), 4–7 — части указателя на системную таблицу UEFI.
Прошивка держит память один к одному, поэтому физический адрес `P` ниже
4 ГБ читается как гостевой `P − r14` (так `pci.saltic` доходит до ECAM).

## На ноутбуке через Ventoy

Ventoy показывает и `.efi`, и `.iso`, если ноутбук загружен в UEFI. Enter,
которым выбирают пункт меню, остаётся в буфере клавиатуры: программа с
«Press any key» сразу выходит, и прошивка грузит следующее по списку. Ждать
конкретную клавишу или не выходить вовсе.

Первый запуск — 01.11.2026, Acer Aspire E5-575G (Kaby Lake): `pci.saltic`
нашла 19 устройств, среди них Ethernet Realtek RTL8111 (`10ec:8168`) и Wi-Fi
Qualcomm Atheros QCA9377 (`168c:0042`).

Вечером 01.11.2026 `rtl8111.saltic` отправила по кабелю (Acer ↔ второй
ноутбук напрямую, линк 1000 Mbit/s) десять UDP-рассылок, все дошли.
Физический адрес арены надо выравнивать на 256 при запуске: прошивка Acer
кладёт программу по неровному адресу, а кольцу дескрипторов нужно
выравнивание на 256, иначе карта не берёт пакет.

Там же, через 7 минут: драйвер принял `ping N` от `tools/talk.py` и на каждый
ответил `echo: ping N` в ту же секунду — первый приёмник команд на Saltic.
Сеть — два ноутбука, соединённых кабелем напрямую; на втором `eno1` без
IP-адреса, поэтому оба скрипта работают через сырой сокет и `sudo`.

Агент, 01.11.2026: на `eno1` профиль NetworkManager `saltic-wire` с адресом
10.0.0.1/24 (`nmcli connection add type ethernet ifname eno1 con-name
saltic-wire ipv4.method manual ipv4.addresses 10.0.0.1/24 ipv6.method
link-local connection.autoconnect-priority 10`). Linux находит Acer по ARP,
`tools/say.py` отвечают `help`, `info`, `pci` (19 устройств текстом) и `mem`
(сырая память железа — конфигурация PCI и регистры карты).

`upload`, 01.11.2026: `cpu.start_image(hi, lo, размер)` — системный вызов 501:
прослойка зовёт `LoadImage` и `StartImage` прошивки на образе из памяти.
Дочерняя программа возвращается к агенту (`visitor` — статус 0). Новая версия
самого агента не возвращается: она сбрасывает карту и слушает сама — так
агент обновился по сети за 1,6 секунды (452 КБ) и заговорил по-русски.

Экран, 01.11.2026: `cpu.wide_console()` — системный вызов 502: перебрать
текстовые режимы консоли прошивки (`QueryMode`), включить самый большой
(`SetMode`), вернуть столбцы × строки. На Acer — 170 × 40 вместо 80 × 25.
Новый агент доехал до ноутбука по сети за 1,6 секунды, без флешки.

`firmware.call`, 01.11.2026: один общий вызов прошивки вместо частных.
`core.cpu.call(hi, lo)` — системный вызов 503: блок в арене (адрес функции,
до 10 аргументов по 8 байт, результат); прослойка раскладывает первые четыре
по `rcx`, `rdx`, `r8`, `r9`, остальные — на выровненный стек. Частные вызовы
501 (`start_image`) и 502 (`wide_console`) ушли из компилятора — теперь это
Saltic в `uefi.saltic`. Команда агента `screen` нарисовала на Acer первые
пиксели: экран 1366 × 768, BGR, строка 1376 пикселей, кадр по адресу
`c0000000`.

Шрифт, 01.11.2026: команды агента `clear` (светлый экран и заголовок 16×32)
и `print <текст>` (строка 12×24). Русский текст рисуется из сырых байтов
пакета — в Saltic нет символа по коду байта. После `clear` агент не пишет в
консоль прошивки: она прокручивала экран вместе с нашими пикселями. На Acer
панграмма «Съешь же ещё этих мягких французских булок, да выпей чаю» —
все буквы на месте.

Установка, 01.11.2026: `volumes` показал, что на диске Acer нет UEFI-раздела
(старая система стояла в режиме BIOS). `prepare-disk` без слова только
показывает выбранный диск (целый, несъёмный, больше 10 ГБ, ровно один);
`prepare-disk ERASE-ACER-DISK` стирает его: GPT, раздел EFI, FAT32. Прошивка
сразу распознала новую FAT32. `upload` + `install` записали агента в
`\EFI\BOOT\BOOTX64.EFI`; после перезагрузки без флешки Acer сам загрузил
Saltic с диска. Обновить систему на диске: `tools/upload.py agent.efi`, затем
`tools/say.py install`, перезагрузка.

Грабли: большие группы байтов (16–64 КБ) через `group.add` исчерпали память —
нули пишутся прямо в арену. Метку тома прошивка берёт из записи в корневом
каталоге, а не из загрузочного сектора, поэтому наш том ищется как
несъёмный, а не по метке.

Часы, 01.11.2026: `uefi.now` читает часы ноутбука (`RuntimeServices→GetTime`).
Агент сразу при старте переходит в свой графический экран (заголовок, часы
справа сверху 16×32), часы перерисовываются раз в секунду из цикла приёма.
В аппаратных часах Acer — UTC (так их вела старая система), агент
показывает UTC+5 с переходом через полночь и конец месяца. Команда `time`.

Журнал, 01.11.2026: каждая команда агенту — строка на экране Acer
(`22:38:48  10.0.0.1  info`, серым 8×16), строки `print` — тёмным 12×24, один
курсор на экране. Русский текст команды рисуется из сырых байтов пакета.
ARP и куски `upload` в журнал не идут. Место кончилось — область под
заголовком очищается, журнал начинается сверху; заголовок и часы остаются.
Ответ `echo` по сети пока теряет кириллицу (нет символа по коду байта).

Память и живучесть, 01.11.2026: агент собирается с кучей 1 ГБ
(`… agent.saltic agent.efi 1073741824 x86_64-uefi`). Файл остаётся ~1 МБ —
память выделяет прошивка по `SizeOfImage`. Раскладка UEFI-образа считается
32-битными словами: обычными числами Saltic размеры выше 256 МБ переполнялись
(на 64 МБ образ байт в байт прежний). Гостевая память должна лежать ниже 4 ГБ
(окно `r14` + 32 бита), поэтому два агента по 1 ГБ рядом не помещаются —
`run` новой версии рядом со старой даёт `GuestBaseAbove4G`. Обновлять агента
на 1 ГБ: `upload` → `install` → перезагрузка; `run` — для маленьких программ.

Полоса загрузки внизу экрана во время `upload`. Главный цикл вечный (раньше
200 млн оборотов кончались за минуты, и агент тихо останавливался), сбой
одного оборота не убивает агента — `info` показывает, сколько их и какой
последний; если агент всё же остановится — красная плашка с причиной на
экране и та же строка рассылкой UDP на порт 5555 (её ловит `tools/listen.py`).

Перезагрузка по сети, 01.11.2026: команда агента `reboot`
(`RuntimeServices→ResetSystem`); агент сначала отвечает «перезагружаюсь».
Через 10 секунд Acer снова на связи с диска. Полный цикл обновления без рук:
`tools/upload.py agent.efi` → `tools/say.py install` → `tools/say.py reboot`
→ `tools/shot.py` — посмотреть результат.

Кусок кода без пересборки агента, 02.11.2026: `tools/snippet.py` собирает
маленькую программу (64 МБ) из куска и запускает её рядом с агентом; то,
что кусок отдаёт через `out`, возвращается через `ExitData`. Первым делом
так прочитаны регистры xHCI: `b4300000`, версия 1.0, 64 слота, 18 портов.

Камера `0408:a030` (Generic HD WebCam) видна через `UsbIo` прошивки, но
поток у неё только изохронный, а прошивка Acer изохронную передачу не
умеет (`Unsupported`). Картинка с камеры — только через свой драйвер xHCI.
