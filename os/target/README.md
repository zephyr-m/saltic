# Targets

Поддерживаемые платформы операционной системы Saltic.

Каждая цель содержит только описание машины, запуск и сборочную конфигурацию.
Переносимые драйверы находятся в `os/drivers`.

Все тела — одна ОС (`docs/OS-core.md`, «Первое требование»). Папка с одним
`README.md` — заглушка: цель записана в план, но ещё не начата.

| Папка | Железо | Бэкенд | Состояние |
|---|---|---|---|
| `qemu_virt/` | QEMU virt | RV32I | ✅ есть |
| `uefi_x86_64/` | Acer и любой ПК с UEFI, Steam Deck | x86-64 (перевод, потом родной) | ✅ есть |
| `rp2350/` | RP2350 | RV32I, потом Thumb-2 | ⬜ заглушка |
| `stm32h7/` | STM32H7 | Thumb-2 (Cortex-M7) | ⬜ заглушка |
| `teensy41/` | Teensy 4.1 | Thumb-2 (Cortex-M7) | ⬜ заглушка |
| `esp32/` | ESP32 | Xtensa LX6 | ⬜ заглушка |
| `esp32s3/` | ESP32-S3 | Xtensa LX7 | ⬜ заглушка |
| `raspberry_pi/` | Raspberry Pi | ARM64 | ⬜ заглушка |
| `orange_pi/` | Orange Pi | ARM64 | ⬜ заглушка |
